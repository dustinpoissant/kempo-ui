Description

The conversations utility saves whole conversations (a list of messages) in the browser's IndexedDB, so they survive a reload, and keeps as many as you like. localStorage is too small and too slow for that: it only stores short strings, about 5 MB for the whole site. IndexedDB stores the messages as they are, dates included, and holds far more. <k-chat persistent-id> uses it, and it works for any list of messages.

Conversations can be sorted into groups (a plain string, such as the name of a chat) so each chat on a site only sees its own. The data lives in one IndexedDB database named kempo-conversations, in this browser only. It is not encrypted, so do not save secrets on a shared computer. Every function rejects if IndexedDB is not available (a private window in some browsers), so wrap calls in try / catch if that matters.

Basic Usage

import {
  saveConversation,
  listConversations,
  getConversation,
  deleteConversation
} from './utils/conversations.js';
const {
  id
} = await saveConversation({
  group: 'support',
  title: 'Refund question',
  messages: [{
    id: '1',
    type: 'outgoing',
    html: '<p>Hi</p>'
  }]
});
// Newest first, without the messages
const list = await listConversations('support');
const {
  messages
} = await getConversation(list[0].id);
await deleteConversation(id);

API Methods

saveConversation({ id, group, title, titleCustom, debug, messages })

Saves a conversation, replacing the saved one with the same id. Everything is optional: with no id a new one is made up. messages can be any list of objects the browser can store (strings, numbers, dates, nested objects and arrays, but not functions).

titleCustom marks a title somebody chose (so it is not replaced by an automatic one). debug is a list of lines of text, a record of what happened with the model, kept with the conversation so it can be exported.

Returns: Promise<{ id, group, title, titleCustom, debug, messages, createdAt, updatedAt }>

getConversation(id)

Returns: Promise<object | undefined>

The saved record, or undefined if there is none with that id.

renameConversation(id, title)

Gives a saved conversation a title of your choice. An empty title goes back to the automatic one. The conversation keeps its place in the list (its updatedAt does not change).

Returns: Promise<boolean> (false if there is no such conversation)

titleOf(messages)

The title a conversation gets by itself: the first 60 characters of the first message that has markdown.

Returns: string

formatConversation(record, { page, browser }?)

A conversation record as one text, to save to a file or paste somewhere: its details (title, id, dates, the page and the browser you pass in), the messages, and the debug record (what was sent to the model, its raw replies, the tool calls). The export button of <k-chat-bubble> uses it.

Returns: string

listConversations(group?)

Lists the saved conversations, of one group or of all of them if you pass no group. The messages and the debug record are left out so the list stays small, use getConversation() to open one.

Returns: Promise<Array<{ id, group, title, titleCustom, createdAt, updatedAt }>> newest first

deleteConversation(id)

Returns: Promise<void>

clearConversations(group?)

Deletes every conversation of the group, or every conversation if you pass no group.

Returns: Promise<void>
