Description

The styles a Page Builder widget has beyond its own settings, kept on the widget as styles. Almost all of them are kempo-css classes the person chooses: the space around the widget (margin) and inside it (padding), a background, a text colour, the text alignment, which corners are rounded, and which sides have a border. The background's opacity is the one style value, because kempo-css has no class for it. A widget also has an id and extra classes.

The page and the builder write them the same way, on the widget's first element. It has no DOM, so a server can use it too.

Basic Usage

import {
  decorate
} from 'kempo-ui/src/utils/styles.js';
const html = decorate('<div>Hello</div>', {
  margin: {
    bottom: 'f'
  },
  align: 'center'
}, 'd-b');
console.log(html);

The Styles Object

{
  margin: {
    top: 'f',
    right: '',
    bottom: 'f',
    left: ''
  },
  padding: {
    top: 'h',
    right: 'h',
    bottom: 'h',
    left: 'h'
  },
  background: 'primary',
  alpha: 80,
  textColour: 'inv',
  align: 'center',
  corners: ['tl', 'tr'],
  sides: ['top'],
  id: 'hero',
  classes: 'extra another'
}
  • margin, padding — a size for each side: '' none, 'q' a quarter space, 'h' half a space, 'f' a whole space.
  • background — one of BACKGROUNDS. alpha is its opacity: a percentage, rounded and held between 0 and 100, and 100 when it is missing.
  • textColour — one of TEXT_COLOURS.
  • align — one of ALIGNS.
  • corners — the rounded corners, from CORNERS. sides — the sides with a border, from SIDES.
  • id — the element's id. classes — extra class names, separated by spaces.

Constants

STYLE_PARTS

The parts of the Styles tab a widget can hide with hideStyles, and the styles each one holds: box (margin, padding, corners, sides), background (background, alpha), textColour, align, id and classes.

SIDES

['top', 'right', 'bottom', 'left']

SIZES

['', 'q', 'h', 'f']

BACKGROUNDS

['default', 'alt', 'inv', 'primary', 'secondary', 'success', 'warning', 'danger']

TEXT_COLOURS

['default', 'muted', 'inv', 'primary', 'secondary', 'success', 'warning', 'danger']

ALIGNS

['left', 'center', 'right']

CORNERS

['tl', 'tr', 'bl', 'br']

Functions

styleClasses(styles)

Returns: Array<string>

The kempo-css classes a widget's styles give it, using the shortest names. A margin or padding on all four sides the same is one class (m, mh, mq), top and bottom the same is my, left and right the same is mx, and anything else is a class per side (mt, mbq). A whole space has no suffix, and padding uses p in place of m. A background is bg-*, a text colour tc-*, an alignment ta-*. All four corners is r and all four sides is b; otherwise there is a class for each one chosen (rtl, rtr, rbl, rbr, bt, br, bb, bl). Extra classes are added when they are plain names (letters, digits, _ and -). A background that is see-through has no class: see styleCss.

styleCss(styles)

Returns: string

The one inline style a widget's styles give it: a background's opacity, when it has a background and less than all of it. It sets the background colour from the kempo-css variable with that opacity, and sets the text colour readable on it, unless a text colour is chosen. '' otherwise.

styleId(styles)

Returns: string

The id the styles give the widget, when it is a valid one (it starts with a letter and has only letters, digits, _ and -), otherwise ''.

cleanSides(value)

Returns: Object

A value with a size for every side. A side that is missing, or is not one of SIZES, is ''.

shownStyles(styles, hidden = [])

hidden: Array<string> (optional)

Names from STYLE_PARTS, the parts a widget hides.

Returns: Object

The styles without the ones in the hidden parts.

supportsStyles(definition)

Returns: boolean

Whether a widget takes styles. The pieces of a widget (sections, columns, tabs) do not: their parent lays them out.

decorate(html, styles, display = '')

html: string

A piece of HTML. Only its first element is changed.

styles: Object

The widget's styles.

display: string (optional)

The widget's display class (d-b or d-ib).

Returns: string

The HTML with the display class and the styles' classes added to the first element's class (a class it already has is not repeated), the styles' inline style added to its style, and the styles' id added as its id unless it already has one.

Examples

Classes From Styles

styleClasses({
  margin: {
    top: 'f',
    right: '',
    bottom: 'f',
    left: ''
  },
  padding: {
    top: 'h',
    right: 'h',
    bottom: 'h',
    left: 'h'
  },
  background: 'primary',
  textColour: 'inv',
  align: 'center',
  corners: ['tl', 'tr', 'bl', 'br'],
  sides: ['top'],
  classes: 'extra'
});
// ['my', 'ph', 'bg-primary', 'tc-inv', 'ta-center', 'r', 'bt', 'extra']

A See-through Background

styleCss({
  background: 'alt',
  alpha: 50
});
// 'background-color: oklch(from var(--c_bg__alt) l c h / 0.5); color: var(--tc)'
styleCss({
  background: 'alt',
  alpha: 100
});
// ''

Decorate an Element

decorate('<div class="x">Hi</div>', {
  margin: {
    bottom: 'f'
  },
  id: 'box'
}, 'd-b');
// '<div class="x d-b mb" id="box">Hi</div>'

Hide Parts a Widget Has Its Own Setting For

shownStyles({
  margin: {},
  background: 'alt',
  alpha: 50,
  align: 'left'
}, ['box', 'background']);
// { align: 'left' }
