Description

The functions that work on a page's tree of widgets. They take a list of nodes (the page's default slot, or any slot) and a registry (a Map of widget definitions by name, from registryOf in pageWidgets). Nothing here touches the DOM, so the Page Builder and a server can share it. It uses the global crypto and structuredClone, which browsers and current versions of Node have.

Functions that change the tree change the list they are given, in place. Those that can fail return the reason as a string or an { error } object, and leave the tree as it was.

Basic Usage

import {
  addWidget,
  findNode
} from 'kempo-ui/src/utils/pageTree.js';
import {
  widgets,
  registryOf
} from 'kempo-ui/src/utils/pageWidgets.js';
const registry = registryOf(widgets);
const nodes = [];
const columns = addWidget(nodes, registry, 'columns');
const found = findNode(nodes, columns.id);
console.log(found.node.slots.default.length);

Nodes

A page is { attrs, slots: { default: [nodes] } }, and each widget on it is a node: { id, type, attrs, slots: { [slotName]: [node, ...] } }. type is the widget's name.

MAX_DEPTH

100: how many levels deep widgets may be nested. place refuses a move or an add that would go deeper.

newId()

Returns: string

A new id: 12 random hex characters.

createNode(type, attrs = {}, slots = {})

Returns: Object

{ id, type, attrs, slots } with a new id. It does not look at the registry, so it has no default settings or children. Use defaultNode for those.

defaultNode(registry, type)

Returns: Object

A new widget at its defaults: each setting that has a default other than '' or false is set, and the children its definition's children lists are made the same way (a Columns widget starts with two columns).

attributeDefault(attribute)

Returns: any

A copy of the setting's default, or false for a boolean and '' for anything else when it has none.

valueAt(attrs, path)

Returns: any

A value inside a widget's attrs by path: 'html' is attrs.html, 'rows.1.0' is attrs.rows[1][0]. A widget marks a part of itself that can be edited on the page with the path of what it edits (data-pb-edit). A path that is not there reads as undefined.

setValueAt(attrs, path, value)

Returns: boolean

Sets the value at a path. The place must exist already (an array position, or an object to put a name on); if it does not, nothing changes and it returns false.

Reading the Tree

walk(nodes, fn)

Calls fn(node, { parent, slot, list, index, depth }) for every node, parents before children. parent is the parent node (null at the top), slot is the name of the slot the node is in ('' at the top), list is the array it is in, and depth is 1 at the top. Return false from fn to skip a node's children.

findNode(nodes, id)

Returns: Object | null

{ node, parent, slot, list, index, depth } for the node with that id, or null.

findSlot(nodes, parentId, slot)

Returns: Array | null

The list a slot of a parent holds, creating the slot if it is not there. With no parentId it is nodes itself. null when the parent is not found.

countNodes(nodes)

Returns: number

How many nodes there are, with their children.

maxDepth(nodes)

Returns: number

The depth of the deepest node. A list of top-level nodes is depth 1.

firstSlotOf(registry, node)

Returns: string | null

The slot a widget's children go into by default (its first), or null for a widget with no slot.

canContain(registry, parentNode, slotName, childType)

Returns: boolean

Whether a widget may be put in this slot of this parent (parentNode is null at the top level). Anything can go in anything: the only requirements are that childType is registered and that the parent has the slot.

isInside(nodes, ancestorId, id)

Returns: boolean

Whether the node id is the node ancestorId or somewhere inside it. Moving a node there would put it inside itself.

sharePlace(nodes, ids)

Returns: boolean

Whether every node in ids exists and they all share one list. This is what selecting several widgets allows.

neighbour(nodes, id)

Returns: string | null

The id to select after a node is removed: its next sibling, else the previous one, else its parent, else null.

sectionOpen(node, parent)

Returns: boolean

Whether an accordion section starts open: what its open setting says. Until any section of the accordion has an open setting, the first section is open.

Adding Widgets

place(nodes, registry, node, parentId, slot, index)

Returns: true | string

Puts an existing node in a parent's slot at an index (parentId null for the top level). It returns true, or the reason it was refused: the parent no longer exists, the widget cannot go in that slot, or it would be nested deeper than MAX_DEPTH.

addWidget(nodes, registry, type, options = {})

options: Object (optional)
  • targetId — the widget to add near. Without it, or when no widget has that id, the new widget goes at the end of nodes.
  • inside — true to put it inside the target, at the end of its slot (its first slot by default). It is refused, with an error, when the target has no slot.
  • slot — the name of the target's slot, with inside.
Returns: { id } | { error }

Adds a new widget at its defaults (defaultNode). Without inside it goes after the target. If the target has a slot with nothing in it and the new widget is not a section, it goes inside the target. If the target's own list will not take it, it goes after the target's parent, and so on up.

insertNodes(nodes, registry, list, options = {})

Returns: { ids } | { error }

Adds nodes that already exist (a saved template's copies), one after the other, the first placed by options as in addWidget. If one cannot be placed, the ones already placed are removed and the error is returned.

Changing the Tree

removeNode(nodes, id)

Returns: Object | null

Takes the node out of its list and returns it, or returns null when it is not found.

removeWidgets(nodes, ids)

Returns: true

Removes each node in ids.

moveWidget(nodes, registry, id, parentId, slot, index)

Returns: true | string

Moves one node to a parent's slot at an index. It returns true, or the reason it was refused: the node is gone, it is a section (see Sections), it would go inside itself, or place refused it. A refused move leaves the node where it was.

moveBy(nodes, registry, ids, step)

Returns: true | string

Moves nodes that share a list, together, by step places (-1 is up, 1 is down). The refusals are 'Nothing is selected', a section, 'Already first' and 'Already last'.

moveOut(nodes, registry, id)

Returns: true | string

Moves a node out of its parent, to sit just after it. 'Already at the top' for a node with no parent.

moveIn(nodes, registry, id)

Returns: true | string

Moves a node into the closest widget before it that has a slot, at the end of that widget's first slot. 'There is nothing before it to move into' when there is none.

Copying

cloneNode(node, freshIds = false)

Returns: Object

A deep copy of a node and its children. With freshIds every copy has a new id.

cloneNodes(nodes, freshIds = false)

Returns: Array

A copy of each node in the list.

freshCopies(nodes)

Returns: Array

A copy of the nodes with fresh ids, for inserting a saved template.

duplicateWidgets(nodes, ids)

Returns: { ids } | { error }

Copies the nodes (with their children, and fresh ids) to sit just after the last of them. ids in the result are the ids of the copies. { error: 'Nothing is selected' } when none of the ids is found.

Sections

A widget whose definition has section: true is a part of another widget (a column, an accordion section, a tab, a slide). It is added, ordered and removed from its parent's settings, never moved on the page, so moveWidget and moveBy refuse it.

Examples

Add a Widget Inside Another

const nodes = [];
const columns = addWidget(nodes, registry, 'columns');
const first = findNode(nodes, columns.id).node.slots.default[0];
const text = addWidget(nodes, registry, 'text', {
  targetId: first.id,
  inside: true
});
findNode(nodes, text.id).depth;
// 3

A Refused Move

moveWidget(nodes, registry, first.id, null, '', 0);
// 'Sections are moved from their parent\'s settings'
moveWidget(nodes, registry, text.id, null, '', 0);
// true

Read and Set a Value by Path

const attrs = {
  rows: [
    ['a', 'b'],
    ['c', 'd']
  ]
};
valueAt(attrs, 'rows.1.0');
// 'c'
setValueAt(attrs, 'rows.1.0', 'C');
// true
