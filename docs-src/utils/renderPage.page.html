Description

Turns a page's widget nodes into an HTML string. It has no DOM and no Lit, so the same code writes a page on a server (server-side rendering) and draws the Page Builder's preview in the browser. PageRenderer uses it too.

A node whose type is not registered is left out of the page. In the builder it is shown as not available, so nothing is lost from view.

Basic Usage

import {
  renderPage
} from 'kempo-ui/src/utils/renderPage.js';
import {
  widgets,
  registryOf
} from 'kempo-ui/src/utils/pageWidgets.js';
const html = renderPage(page.slots.default, registryOf(widgets));

API

renderPage(nodes, registry, options = {})

nodes: Array

A list of widget nodes: a page's slots.default. A node is { id, type, attrs, slots }.

registry: Map

The widget definitions by name: registryOf(widgets) from pageWidgets.

options: Object (optional)
  • editor — true for the builder's version. Every widget's first element gets data-pb-id, data-pb-title and tabindex="0", containers are marked as places widgets can be dropped (data-pb-slot="default"), and a widget with an editorTag uses that tag. Default false.
  • sanitize — function(html) applied to content in mode 'html' (a text widget) and to every table cell. The default does nothing. See Rendering on a Server.
Returns: string

The HTML of the widgets, one after the other. The styles of each widget that takes them (margin, padding, background and the rest, not a section) and its display class are added to its first element. A widget is a block (d-b), or inline-block (d-ib) when its definition has inline, unless its definition gives display.

collectModules(nodes, registry, options = {})

options.editor: boolean (optional)

Also include each widget's editor module. Default false.

Returns: Array<string>

The module URLs the page's widgets need (the page URLs of their definitions), each once. They are made from import.meta.url, so they are absolute: file: URLs in Node. See Rendering on a Server.

createRenderer(registry, options = {})

Makes the render context (ctx) that renderPage uses, with the same editor and sanitize options. A widget's render function receives it. See The Render Context.

Returns: Object

attributeString(definition, node, skip = [])

definition: Object

The widget's definition.

node: Object

The widget's node.

skip: Array<string> (optional)

Setting names to leave out.

Returns: string

The widget's attributes as a string that starts with a space, or ''. Only settings that are set and differ from their default are written. Settings marked virtual stay in the tree and are never written. The attribute is named by the setting's attr, or its name. A boolean with format: 'text' is written as name="value"; any other boolean is written as the bare name when it is true. Arrays and objects are written as JSON. Values are escaped.

escapeText(value)

Escapes &, < and >. null and undefined become ''.

Returns: string

escapeAttribute(value)

Does what escapeText does, and also escapes " and ', so the value is safe inside a quoted attribute.

Returns: string

The Render Context

A widget definition may give tag, editorTag, classes(attrs), style(attrs), content and render. With none of them, the widget is drawn as its tag element. A render(node, ctx, info, definition) function returns the widget's whole HTML. info is { index, parent, slot }: where the widget is. ctx has:

  • ctx.standard(node, info, options) — the widget's own element, built from its definition. options is { tag, classes, style, content, skip, extra }: a different tag, more classes, more inline style, the element's content in place of the one from content, setting names to leave out of the attributes, and extra attributes as a string. A container (a widget with slots) gets data-pb-slot="default" in the builder, and its children inside it. Void elements such as hr have no content or closing tag.
  • ctx.children(node, slot = 'default') — the HTML of the widgets in one of the node's slots. In a slot that is not default, the first tag of each child gets a slot attribute.
  • ctx.mark(node, definition, extra = '') — the builder's marks for the widget's element (data-pb-id, data-pb-title, extra, tabindex), or '' on the page.
  • ctx.attributes(definition, node, skip) — the same as attributeString.
  • ctx.node(node, info) — the HTML of any node, with its styles added.
  • ctx.escapeText, ctx.escapeAttribute — the escape functions above.
  • ctx.editor, ctx.sanitize, ctx.registry — what the context was made with.

A definition's content is { name, mode }: the setting name is the element's text, and mode is 'html' (passed through sanitize), 'raw' (written as it is) or anything else (escaped as text).

Rendering on a Server

This file has no DOM, so a server can import it to prerender a page. Import it with pageWidgets rather than the k-page-renderer element, which defines custom elements.

Pass a sanitize function on a server. The default does nothing, and kempo-ui's sanitizeHtml needs a browser DOM. Without one, the HTML of text widgets and table cells is written exactly as it was saved. Markdown text is escaped, and the HTML widget is written raw on purpose, so neither goes through sanitize: only let people you trust edit an HTML widget. 
const html = renderPage(page.slots.default, registryOf(widgets), {
  sanitize: html => mySanitizer(html)
});

collectModules gives file: URLs in Node. Map them to the URLs your site serves the files from before you put them in a page:

const scripts = collectModules(page.slots.default, registryOf(widgets)).map(url => url.replace(/^.*\/src\//, '/kempo-ui/src/'));

Examples

A Page and the Builder's Version

const nodes = [{
  id: 'a',
  type: 'text',
  attrs: {
    html: '<p>Hello</p>',
    styles: {
      margin: {
        bottom: 'f'
      },
      align: 'center'
    }
  },
  slots: {}
}];
renderPage(nodes, registry);
// <div class="d-b mb ta-center"><p>Hello</p></div>
renderPage(nodes, registry, {
  editor: true
});
// <div contenteditable="true" data-pb-id="a" data-pb-title="Text" tabindex="0" class="d-b mb ta-center"><p>Hello</p></div>

Only the Settings That Differ

attributeString(registry.get('tabs'), {
  attrs: {
    hashRouting: true,
    persistentId: 'main',
    fixedHeight: false
  }
});
// ' hash-routing persistent-id="main"'

Modules a Page Needs

collectModules([{
  id: 'x',
  type: 'button',
  attrs: {},
  slots: {}
}], registry);
// ['file:///.../src/components/Icon.js']
