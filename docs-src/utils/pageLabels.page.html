Description

How the Page Builder names a widget: its icon, its title in the tree and the settings, a short hint of what it says or points to, and the label of a section (a column by its place, a tab or accordion section by its heading). The builder uses it. It imports Lit and Icon.js, so it needs a browser.

Basic Usage

import {
  titleOf,
  hintOf,
  sectionLabelOf
} from 'kempo-ui/src/utils/pageLabels.js';
import {
  widgets,
  registryOf
} from 'kempo-ui/src/utils/pageWidgets.js';
const registry = registryOf(widgets);
const node = {
  id: 'a',
  type: 'button',
  attrs: {
    label: 'Buy now'
  },
  slots: {}
};
console.log(`${titleOf(registry, node)}: ${hintOf(node)}`);

API

widgetIcon(definition)

definition: Object

A widget definition.

Returns: TemplateResult

A Lit template for the widget's icon: a <k-icon> from its iconSrc (the path of an icon file), or else from its icon name (help when it has none, or when definition is missing). A definition's iconRotation is passed to the icon as its rotation, in degrees.

titleOf(registry, node)

Returns: string

The title of the node's widget, or the node's type when it is not registered.

hintOf(node)

Returns: string

A short hint of what a widget says or points to, at most 40 characters. For a text widget it is the text, with its tags and extra spaces removed. For any other widget it is the first of its label, title, name, condition, src and href settings that has a value. '' when there is none.

sectionLabelOf(node, index)

index: number

The section's place in its parent, from 0.

Returns: string

The label of a section: Column 1 for a column, Slide 1 for a slide, Tab spacer for a tab spacer, and for any other section its label or title setting, or Section 1 when it has neither. The number is index + 1.
