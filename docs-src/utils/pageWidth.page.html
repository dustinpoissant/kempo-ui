Description

Sets the custom property --page-width on the root element to the width of the page without its vertical scrollbar, and keeps it up to date. It exports nothing: import it for its effect.

Basic Usage

Import the file once, then use the property in CSS. 100vw is the fallback for a page where the file has not loaded:

import 'kempo-ui/src/utils/pageWidth.js';
.full-bleed {
  width: var(--page-width, 100vw);
}

How It Works

--page-width is document.documentElement.clientWidth in px. A ResizeObserver on the root element updates it, so it follows the window being resized and the scrollbar appearing or going away.

Most browsers include the vertical scrollbar in 100vw, so a full-width element sized with 100vw makes the page scroll sideways. --page-width does not include it.

It needs a browser: it reads document and uses ResizeObserver when it loads.

Where It Is Used

The Page Builder's Fullscreen breakout widget and the Hero widget's breakout size themselves from --page-width. The widgets' page modules load this file, both on the page and in the builder's frame.
