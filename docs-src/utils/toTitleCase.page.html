Description

The toTitleCase utility function converts strings to title case format. It handles camelCase, snake_case, kebab-case, and regular text, converting them into properly capitalized title case with spaces between words.

Note: This function is now part of the string utilities module.

Basic Usage

Import and use the toTitleCase function to convert strings to title case:

import { toTitleCase } from '../src/utils/string.js';

const result = toTitleCase('helloWorld');
console.log(result); // "Hello World"

Parameters

str: string

The string to convert to title case. Can be in any format (camelCase, snake_case, kebab-case, or regular text).

Return Value

string

The input string converted to title case with proper spacing and capitalization.

Examples

Converting camelCase

toTitleCase('firstName');     // "First Name"
toTitleCase('customerAddress'); // "Customer Address"
toTitleCase('userId');         // "User Id"

Converting snake_case

toTitleCase('first_name');     // "First Name"
toTitleCase('customer_address'); // "Customer Address"
toTitleCase('user_id');         // "User Id"

Converting kebab-case

toTitleCase('first-name');     // "First Name"
toTitleCase('customer-address'); // "Customer Address"
toTitleCase('user-id');         // "User Id"

Converting regular text

toTitleCase('hello world');     // "Hello World"
toTitleCase('the quick brown fox'); // "The Quick Brown Fox"

Practical Use Case: Table Column Headers

const columns = ['firstName', 'lastName', 'emailAddress'];

const headers = columns.map(col => toTitleCase(col));
// ["First Name", "Last Name", "Email Address"]
