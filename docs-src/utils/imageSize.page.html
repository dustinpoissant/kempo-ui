Description

Loads an image in the browser and resolves its natural size, or null when it cannot be loaded. The Page Builder uses it to measure the photos of a Photo viewer widget: in the widget's settings when a photo's address is set, and when a saved page is shown, for photos that have no stored size. The size is kept on the photo, and a grid of photos takes its ratio from the one closest to square. It needs a browser, because it uses Image.

Basic Usage

import imageSize from 'kempo-ui/src/utils/imageSize.js';
const size = await imageSize('/media/photo.jpg');
if (size) {
  console.log(`${size.width} x ${size.height}`);
}

Parameters

src: string

The address of the image.

Returns: Promise<{ width: number, height: number } | null>

The image's naturalWidth and naturalHeight once it has loaded, or null when it fails to load. The promise never rejects.
