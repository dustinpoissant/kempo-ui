Slots

A single-row toolbar for controls. It has three slots — the default slot on the left, center and right — spaced with flexbox. It never wraps to a second row: when the controls no longer fit, they are moved one at a time into a vertical-ellipsis “more” menu, and they move back as the bar grows. The “more” menu is a kc-menu. The controls keep working from it, since they are only moved to a different slot.

The examples are table toolbars. Drag the right edge of each example to resize it. The controls keep acting on the table from the menu, since they are only moved to a different slot.

Basic Usage

Put any controls in the slots (here, table controls in the table’s top slot). By default the controls in the right slot are moved into the menu first, starting with the last one, then the center slot, then the default slot.

<k-table>
  <k-control-bar slot="top">
    <kc-tc-search></kc-tc-search>
    <kc-tc-field-sort-hide></kc-tc-field-sort-hide>
    <kc-tc-export-csv slot="center"></kc-tc-export-csv>
    <kc-tc-export-json slot="right"></kc-tc-export-json>
    <kc-tc-page-size slot="right"></kc-tc-page-size>
  </k-control-bar>
</k-table>

Collapse Order

Use collapse-order to choose which slots are emptied first. It is a space-separated list of right, center and left (or default). Within a slot the last control is always moved first. Here the left side goes first.

<k-control-bar slot="top" collapse-order="left center right"> ... </k-control-bar>

Controls That Stay

Menus (kc-menu, kc-vid-menu, k-dropdown) and kc-spacer are never moved into the “more” menu. Add the no-collapse attribute to keep any other control in the bar, like the search here.

<k-control-bar slot="top">
  <kc-tc-search no-collapse></kc-tc-search> ... </k-control-bar>

Priority

Give a control a priority to keep it in the bar longer. The bar moves controls with the lowest priority into the “more” menu first (default 0, a bare priority means 1, and a negative one moves before the controls that have none), following collapse-order within each priority. As the bar keeps shrinking, even the high-priority controls are moved. Unlike no-collapse, they are not kept forever. Here the search stays the longest, then the page size.

<k-table>
  <k-control-bar slot="top">
    <kc-tc-search priority="2"></kc-tc-search>
    <kc-tc-field-sort-hide></kc-tc-field-sort-hide>
    <kc-tc-export-csv slot="center"></kc-tc-export-csv>
    <kc-tc-export-json slot="right"></kc-tc-export-json>
    <kc-tc-page-size slot="right" priority="1"></kc-tc-page-size>
  </k-control-bar>
</k-table>

Control Groups

Wrap controls in a <k-control-group> to move them into the “more” menu all at once. The group counts as a single control, so it is moved whole and kept together. To move its controls one at a time instead, see Splitting a Group.

<k-table>
  <k-control-bar slot="top">
    <kc-tc-search></kc-tc-search>
    <k-control-group slot="right">
      <kc-tc-export-csv></kc-tc-export-csv>
      <kc-tc-export-json></kc-tc-export-json>
    </k-control-group>
    <kc-tc-page-size slot="right"></kc-tc-page-size>
  </k-control-bar>
</k-table>

Splitting a Group

Add split to a <k-control-group> to move its controls into the “more” menu one at a time instead of together. Each control is ranked by its own priority, or by the group’s when it has none, and a control marked no-collapse stays in the bar. A control that moves leaves its group and is listed in the menu in the order it had in the group. It goes back when there is room, and the group disappears when nothing is left in it. In this example Export CSV never moves, while Export JSON does.

<k-table>
  <k-control-bar slot="top">
    <kc-tc-search></kc-tc-search>
    <k-control-group split slot="right">
      <kc-tc-export-csv no-collapse></kc-tc-export-csv>
      <kc-tc-export-json></kc-tc-export-json>
    </k-control-group>
    <kc-tc-page-size slot="right"></kc-tc-page-size>
  </k-control-bar>
</k-table>

Links and Buttons

The bar is not only for kc-* controls. Plain links and buttons, such as a navbar, collapse into the “more” menu the same way, with no controlled component needed. In the menu they become full-width rows. priority, no-collapse, soft-min-width and the slots all work on them too. Controls that are not kc-* elements have no menu-text or in-menu styling, so they keep whatever markup you gave them.

<k-control-bar>
  <a href="#" class="btn">Home</a>
  <a href="#" class="btn">Products</a>
  <a href="#" class="btn">Pricing</a>
  <a href="#" class="btn">Docs</a>
  <a href="#" class="btn" slot="right">Log in</a>
  <button class="btn primary" slot="right">Sign up</button>
</k-control-bar>
Home Products Pricing Docs Log in

JavaScript Reference

Constructor

new ControlBar();

Requirements

Import the component, plus any controls you slot into it. The bar does not need a host: controls find their own host (closest('[controlled]')) wherever they are slotted.

Properties

Property / Attribute Type Default Description
collapseOrder / collapse-order String 'right center left' The order the slots are emptied into the “more” menu. left and default both mean the default slot.

Attributes on Controls and Hosts

Attribute On Description
no-collapse A control in the bar Keeps the control in the bar; it is never moved into the “more” menu.
soft-min-width A control in the bar A width (8rem, 120px, or a bare number of pixels). While the bar decides what to move into the “more” menu, the control is kept at least this wide, so the other controls move into the menu earlier. When nothing is left to move, the control is let go and shrinks below it instead of overflowing the bar. The seek bar in the Audio and Video presets uses 8rem. Do not set an inline min-width on the control, as the bar sets and clears it.
priority A control in the bar A number, default 0 (a bare attribute means 1). Controls with a higher priority are moved into the “more” menu later than lower ones, but are still moved when the bar gets small enough.
in-menu A control Set by the bar while a control is in the “more” menu (and by kc-menu on its controls). The control then shows its menu-text slot, the label next to its icon, on its own row. Do not set it yourself.
has-control-bar The controlled host Set by the bar on the closest [controlled] element. HtmlEditor, CodeEditor, MarkdownEditor and Pagination use it to let the toolbar region fill the width, which the bar needs to know when to collapse. Do not set it yourself.

Slots

Slot Description
(default) Controls on the left.
center Controls in the middle.
right Controls on the right. The “more” menu is placed after them.
overflow Set by the bar on the controls that are in the “more” menu. Do not set it yourself.
