Slots

A small floating button (FAB) that opens and closes an <k-aside>. It sits in a corner of the screen, shows a menu icon by default, and is linked to its aside with the for attribute. It extends Button, so it has the default button look and can be restyled with classes.

Hidden Under an Open Aside

By default the button is hidden while its aside is open, because the aside covers the corner. Clicking it opens the aside, and the aside’s own toggle or backdrop closes it again.

<k-aside id="menu" state="offscreen">
  <nav>
    <h3>Menu</h3>
    <a href="#">Dashboard</a>
    <a href="#">Settings</a>
  </nav>
</k-aside>
<k-aside-btn for="menu"></k-aside-btn>

Pushed Beside an Open Aside

Add push to keep the button visible. When the aside opens, the button moves to sit beside it at the aside’s width. It only moves for a corner on the same side as the aside.

<k-aside id="push-menu" main="push" state="offscreen">
  <nav>
    <h3>Menu</h3>
    <a href="#">Dashboard</a>
    <a href="#">Settings</a>
  </nav>
</k-aside>
<k-main>
  <k-aside-btn for="push-menu" push></k-aside-btn>
</k-main>

Corners

position sets the corner, as "top left" (default), "top right", "bottom left" or "bottom right".

<k-aside-btn for="menu" position="bottom right"></k-aside-btn>

Custom Icon

The menu icon is the default slot content. Put any icon in the button to replace it.

<k-aside-btn for="menu">
  <k-icon name="settings"></k-icon>
</k-aside-btn>

Custom Styling

The button uses the default button styling. Add classes to the element to change it, the same way as any other button, for example a background color from a class or a --btn_bg variable.

<style>
  .fab-brand {
    --btn_bg: var(--c_primary);
    --btn_bg__hover: var(--c_primary__hover);
    --btn_tc: var(--tc_on_primary);
  }
</style>
<k-aside-btn for="menu" class="fab-brand"></k-aside-btn>

Desktop and Mobile

The aside collapses to its rail on desktop, with the arrow in its header. On mobile it overlays the content, the header shows an X that closes it, and the button is shown only then, using the kempo-css d-n m-d-b classes, to reopen it, and a spacer at the top of the content keeps the button from covering it. The iframe below is resizable, so drag its handle to narrow it and switch between the two.

<k-aside id="responsive-aside" main="push" mobile-main="overlay" push-from-offscreen="collapsed" overlay-from-collapsed="offscreen" state="expanded" style="--aside_padding: 0;">
  <k-aside-toggle>
    <h5 class="m-0">Kempo Admin</h5>
  </k-aside-toggle>
  <k-aside-item icon="cards" href="#" active>Dashboard</k-aside-item>
  <k-aside-item icon="settings" href="#">Settings</k-aside-item>
</k-aside>
<k-main>
  <div style="height:4rem" class="d-n m-d-b"></div>
  <h2>Dashboard</h2>
  <p>On desktop the aside pushes this content and collapses to its rail. On mobile it overlays the content, the X closes it, and the button reopens it.</p>
</k-main>
<k-aside-btn for="responsive-aside" class="d-n m-d-b"></k-aside-btn>

JavaScript Reference

Requirements

Import AsideBtn.js. The for attribute must match the id of an <k-aside>. The aside may come before or after the button in the document.

Properties

for: string

The id of the aside this button opens and closes. Syncs to the for attribute.

position: string

The corner the button sits in: "top left" (default), "top right", "bottom left" or "bottom right". Syncs to the position attribute.

push: boolean

When true, the button stays visible and moves beside the aside while it is open. When false (default), it is hidden while the aside is open. Syncs to the push attribute.

label: string

The accessible name, set as aria-label. Defaults to "Menu".

aside-open

Reflected while the aside is open (any state other than offscreen). Use it in CSS to style the button while its aside is open.

Slots

default

Replaces the default menu icon. Leave it empty to show the menu icon.

Methods

Clicking the button, or pressing Enter or Space on it, opens its aside when it is closed (expand()) and hides it when it is open (hide()). A pushed aside is hidden completely, not collapsed to its rail. The button inherits the keyboard behavior and disabled from Button.
