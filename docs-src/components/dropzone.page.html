Basic Usage

An area with a dashed border to drop files on. Clicking it, or pressing Enter or Space while it has focus, opens the file picker. The dropzone only collects files: it reports them in a files event and leaves what to do with them (upload them, read them, show a preview) to your code.

<k-dropzone id="example1"></k-dropzone>
<p id="result1" class="tc-muted">Nothing dropped yet.</p>
<script type="module">
  import '/src/components/Dropzone.js';
  document.getElementById('example1').addEventListener('files', ({ detail }) => {
    document.getElementById('result1').textContent = detail.files.map(file => file.name).join(', ') || 'Nothing accepted.';
  });
</script>

Several Files

It takes one file by default: if several are dropped, the first is kept and the rest are reported as rejected. Add multiple to take them all.

<k-dropzone multiple></k-dropzone>

Limiting the Types

accept works like the attribute of a file input: a comma separated list of extensions (.pdf), types (video/mp4) and families (image/*). It limits what the picker shows, and files dropped on the area are checked against it too, so a file of another type is not reported in files but in rejected.

<k-dropzone multiple accept="image/*,video/*"></k-dropzone>

Label and Custom Content

The text defaults to a sentence that follows multiple. Set label to say something else, or put your own content inside to replace the icon and the text.

<k-dropzone label="Drop your logo here"></k-dropzone>

<k-dropzone>
  <k-icon name="image"></k-icon>
  <strong>Add a cover photo</strong>
</k-dropzone>

Disabled

A disabled dropzone is dimmed and does nothing: it does not open the picker, show a drag, or report files.

<k-dropzone disabled></k-dropzone>

Form Integration

The dropzone is form-associated. With a name, the files it accepts are submitted with the form, as a file input's are. A new accepted drop replaces the previous files, and a drop with no accepted files keeps them. required blocks submission until a file is chosen. Resetting the form clears the files.

<form>
  <k-dropzone name="attachments" multiple required></k-dropzone>
  <button type="reset">Reset</button>
</form>

Read-only

A read-only dropzone keeps the files it holds and still submits them, but it does not open the picker, show a drag, or take new files. It appears at 75% opacity.

<k-dropzone readonly></k-dropzone>

JavaScript Reference

Requirements
import 'kempo-ui/src/components/Dropzone.js';
Attributes
  • accept (String): what it takes, as a file input's accept. Default: everything.
  • multiple (Boolean, written without a value): take more than one file. Default: one.
  • disabled (Boolean, written without a value): dim it and ignore clicks, keys and drops.
  • readonly (Boolean, written without a value): keep the files it holds and submit them, but ignore clicks, keys and drops. Dimmed to 75%.
  • name (String): the form field name. The accepted files are submitted under it.
  • required (Boolean, written without a value): at least one file must be chosen before the form can be submitted.
  • label (String): the text shown with the icon. Default: a sentence that follows multiple.
  • dragging (Boolean, set by the component): present while files are being dragged over it, for your own styling.
Events
  • files: files were dropped or picked. detail.files are the ones it takes and detail.rejected the ones it does not (they do not match accept, or are more than one when multiple is off). It bubbles and is composed.
Methods
  • open(): opens the file picker, as a click does. Nothing happens while disabled or read-only.
  • files (read-only getter): a copy of the accepted files the dropzone holds as its form value.
Slots and Parts
  • The default slot replaces the icon and the text.
  • Part zone: the dashed area, to restyle from outside.
