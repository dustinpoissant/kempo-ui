Basic Usage

The k-media-gallery component shows a mix of images, videos and audio (and anything else you register, see Custom Types) the way an online store does: a large stage, a strip of thumbnails, and arrows to move between items. Each item is a k-media-gallery-item child. Each item is shown by the type that matches its file extension, images by default, videos with Video and audio with Audio. Set type on an item to choose the type yourself. Click an image to open it fullscreen (videos keep their own click-to-play and fullscreen control, and you can reach them in the fullscreen viewer with the arrows or thumbnails). Use the arrows, the thumbnails, the arrow keys, or swipe on a touch screen to move between items.

<k-media-gallery>
  <k-media-gallery-item src="../media/civic.jpg" alt="Honda Civic Type R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/corvette.jpg" alt="Chevrolet Corvette C8"></k-media-gallery-item>
  <k-media-gallery-item src="../media/evo.mp4" poster="../media/evo.jpg" alt="Mitsubishi Lancer Evolution"></k-media-gallery-item>
  <k-media-gallery-item src="../media/gtr.jpg" alt="Nissan GT-R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/nsx.jpg" alt="Honda NSX"></k-media-gallery-item>
</k-media-gallery>

Thumbnails on Top

Ratio and Video Controls

Every item is fitted inside the stage, so items of different shapes come out the same size. Set the shape with ratio (any CSS aspect ratio, 1/1 by default). The controls attribute is passed to inline videos (minimal by default, see Video). In fullscreen, videos always use the normal controls.

<k-media-gallery ratio="16/9" controls="normal">
  <k-media-gallery-item src="../media/civic.jpg" alt="Honda Civic Type R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/corvette.jpg" alt="Chevrolet Corvette C8"></k-media-gallery-item>
  <k-media-gallery-item src="../media/evo.mp4" poster="../media/evo.jpg" alt="Mitsubishi Lancer Evolution"></k-media-gallery-item>
  <k-media-gallery-item src="../media/gtr.jpg" alt="Nissan GT-R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/nsx.jpg" alt="Honda NSX"></k-media-gallery-item>
</k-media-gallery>

Custom Thumbnails

An image's thumbnail is the image itself and a video's thumbnail is its poster. Use thumb to choose a different thumbnail. Videos get a play badge on their thumbnail.

<k-media-gallery>
  <k-media-gallery-item src="../media/civic.jpg" alt="Honda Civic Type R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/evo.mp4" poster="../media/evo.jpg" thumb="../media/corvette.jpg" alt="Mitsubishi Lancer Evolution"></k-media-gallery-item>
  <k-media-gallery-item type="video" src="../media/evo-tagged.mp4" alt="Tagged video"></k-media-gallery-item>
</k-media-gallery>

Audio

Audio files (mp3, wav, flac, aac, m4a, ogg, opus) are played with Audio, with a visualizer that draws the sound as it plays. An item with a poster shows it as cover art above the player, and one without lets the visualizer fill the stage. The controls attribute is passed to the player like it is to videos. The visualizer needs a readable file, see Audio. A sound that is playing carries on when it goes fullscreen, on the same player, which is shown as a square that fits the screen. ogg is treated as audio, use type="video" for a video in that format.

<k-media-gallery>
  <k-media-gallery-item src="../media/evo.jpg" alt="Mitsubishi Lancer Evolution"></k-media-gallery-item>
  <k-media-gallery-item src="../media/vibedepot-tagged.mp3" poster="../media/corvette.jpg" alt="Cover art"></k-media-gallery-item>
  <k-media-gallery-item src="../media/vibedepot-sweet.mp3"></k-media-gallery-item>
</k-media-gallery>

Custom Types

Teach the gallery new kinds of media with MediaGallery.register(). Give it the file extensions to handle and a custom element tag to show them, a 3D model viewer for .stl, a PDF viewer for .pdf, and so on. The gallery creates one of your elements for each item and copies the item's attributes onto it, so it gets src and anything else you put on the item. It also gets a fullscreen attribute while it is in the fullscreen viewer. Fit the element to the stage, it is sized to fill it.

<k-media-gallery id="docsGallery">
  <k-media-gallery-item src="../media/gtr.jpg" alt="Nissan GT-R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/kempo-helper.md"></k-media-gallery-item>
  <k-media-gallery-item src="../media/nsx.jpg" alt="Honda NSX"></k-media-gallery-item>
</k-media-gallery>
<script type="module">
  import MediaGallery from '../../src/components/MediaGallery.js';
  class TextViewer extends HTMLElement {
    static observedAttributes = ['src'];
    connectedCallback() {
      Object.assign(this.style, {
        overflow: 'auto',
        padding: '1rem',
        boxSizing: 'border-box',
        whiteSpace: 'pre-wrap'
      });
    }
    async attributeChangedCallback(name, oldValue, src) {
      this.textContent = await (await fetch(src)).text();
    }
  }
  customElements.define('text-viewer', TextViewer);
  MediaGallery.register('text', {
    extensions: ['txt', 'md'],
    tag: 'text-viewer',
    icon: 'file-text',
    label: 'document'
  });
</script>

Render Function

For full control pass a render function instead of a tag. It is given the item and returns a lit template (or a DOM node). A node you return is reused as is, so create it once and keep it if it holds state. An item with no src, or an unknown extension, needs type set to pick the type.

<k-media-gallery id="swatchGallery" ratio="4/3">
  <k-media-gallery-item src="../media/civic.jpg" alt="Honda Civic Type R"></k-media-gallery-item>
  <k-media-gallery-item type="swatch" color="#c0392b" alt="Red"></k-media-gallery-item>
  <k-media-gallery-item type="swatch" color="#2980b9" alt="Blue"></k-media-gallery-item>
</k-media-gallery>
<script type="module">
  import MediaGallery from '../../src/components/MediaGallery.js';
  import {
    html
  } from '../../src/lit-all.min.js';
  MediaGallery.register('swatch', {
    icon: 'dot',
    label: 'color',
    render: item => html`
      <div style="width: 100%; height: 100%; min-height: 12rem; display: flex; align-items: center; justify-content: center; background: ${item.getAttribute('color')}; color: #fff; font-size: 2rem;">
        ${item.alt}
      </div>
    `
  });
</script>

Programmatic Control

Use the index property or the goTo(), next(), previous(), open() and close() methods, and listen to change events.

<k-media-gallery id="productGallery">
  <k-media-gallery-item src="../media/civic.jpg" alt="Honda Civic Type R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/corvette.jpg" alt="Chevrolet Corvette C8"></k-media-gallery-item>
  <k-media-gallery-item src="../media/gtr.jpg" alt="Nissan GT-R"></k-media-gallery-item>
  <k-media-gallery-item src="../media/nsx.jpg" alt="Honda NSX"></k-media-gallery-item>
</k-media-gallery>
<button id="goLast">Last</button>
<button id="openBtn">Open Fullscreen</button>
<span id="status"></span>
<script type="module">
  const gallery = document.getElementById('productGallery');
  const status = document.getElementById('status');
  gallery.addEventListener('change', e => {
    status.textContent = `Showing ${e.detail.index + 1}`;
  });
  document.getElementById('goLast').addEventListener('click', () => gallery.goTo(3));
  document.getElementById('openBtn').addEventListener('click', () => gallery.open());
</script>

JavaScript Reference

Constructor

Extends ShadowComponent
new MediaGallery()

Creates a new MediaGallery instance. Configuration is done through attributes or properties. Items are k-media-gallery-item children, add or remove them (or change their attributes) and the gallery updates.

Static Methods

MediaGallery.register(name: string, definition: object): MediaGallery

Registers a media type, or replaces one (so you can swap the built-in video or audio player). definition is described in Type Definition. It needs a tag or a render function. A later registration wins when two types claim the same extension. Galleries already on the page update.

MediaGallery.unregister(name: string): MediaGallery

Removes a type and its extensions.

const gallery = document.querySelector('k-media-gallery');
// add (optionally at an index) and remove items
const item = gallery.addItem({
  src: 'shirt-back.jpg',
  alt: 'Back of the shirt'
});
gallery.addItem({
  src: 'shirt.mp4',
  poster: 'shirt-poster.jpg'
}, 0);
gallery.removeItem(2);
// or use the DOM
item.setAttribute('src', 'shirt-side.jpg');
// swap a built-in
MediaGallery.register('video', {
  extensions: ['mp4', 'webm'],
  tag: 'my-video-player'
});
MediaGallery.unregister('text');

Type Definition

The built-in types are image (jpg, jpeg, png, gif, webp, avif, svg, bmp), video (mp4, webm, ogv, mov, m4v) and audio (mp3, wav, flac, aac, m4a, oga, ogg, opus), registered the same way you register your own.

extensions: Array<string>

File extensions, with or without the dot, any case. Defaults to the type name, so register('stl', ...) handles .stl.

tag: string

The custom element that shows the media. One is created for each item, and one more for the fullscreen viewer. It gets all of the item's attributes (except type, thumb, class and style) and a fullscreen attribute in the viewer.

render: (item, context) => TemplateResult | Node

Shows the media, instead of tag. item is the k-media-gallery-item. context is { gallery, fullscreen, active }: the gallery, whether this is for the fullscreen viewer, and whether this item is the one being shown.

shared: boolean

By default the fullscreen viewer gets its own copy of the media, which starts over. With shared: true there is one element, and it is moved between the slide and the fullscreen viewer, so playback, scroll position or a 3D camera carry on where they were. The element has to survive being removed from the page and added again. Audio is shared, so a sound that is playing carries on when it goes fullscreen and when it comes back. A render function of a shared type is called with fullscreen set for each place and has to return the same element every time.

icon: string

The name of a Icon shown on the thumbnail. It marks the type (the play button on a video), and fills the thumbnail when there is no image.

label: string

The word used in the thumbnail's accessible name, "Show label 2". Defaults to the type name.

thumb: (item) => string

Returns the default thumbnail URL of an item, used when it has no thumb attribute.

load: () => Promise

Called before the type is rendered. Use it to import() your component only when a gallery needs it. It is called every time, so rely on the module cache.

pause: (element) => void

Called with the element of an item the gallery moves away from, to stop it playing. Defaults to calling element.pause() when it has one.

Requirements

  • ShadowComponent
  • Icon
  • Video (loaded when a video is shown)
  • Audio and its visualizer (loaded when audio is shown)

Properties

index: number

The index of the item being shown. Starts at 0. Syncs with the index attribute.

thumbsPosition: string

Where the thumbnails go: left (default), top, right or bottom. Syncs with the thumbs-position attribute.

ratio: string

The shape of the stage as a CSS aspect ratio such as 4/3. Defaults to 1/1. Syncs with the ratio attribute.

controls: string

The Video control set for inline videos: minimal (default), normal, full or none. Syncs with the controls attribute.

visualizer: string

The visualizer shown with audio: bars (default), wave or none (the cover art, or an icon, above the player). Syncs with the visualizer attribute.

fullscreen: boolean

Whether the fullscreen viewer is open. Syncs with the fullscreen attribute.

noFullscreen: boolean

Turns the fullscreen viewer off: clicking an image does nothing and open() has no effect. The page builder draws its gallery this way, so clicking it only selects it. Syncs with the no-fullscreen attribute.

keyboardControls: boolean

Whether the arrow keys move between items and Escape closes the fullscreen viewer (default: true). Arrow keys work while focus is inside the gallery, or anywhere while fullscreen. Syncs with the keyboard-controls attribute.

items: Array<MediaGalleryItem>

Read-only. The k-media-gallery-item children.

Item Attributes

Attributes of k-media-gallery-item. An item draws nothing itself, the gallery reads it.

src: string

The URL of the image or video.

type: string

The name of a registered type (image, video, audio or your own). If omitted it comes from the extension of src, and an unknown extension is an image.

poster: string

Video and audio. The image shown before the video plays, or the cover art of the audio. Also the default thumbnail.

thumb: string

The thumbnail image. Defaults to the image itself, or the poster for video and audio.

Any other attribute is passed along to the element of a tag type, and is readable by a render function with item.getAttribute().

alt: string

Alternative text for the image.

Methods

addItem(attributes?: object, index?: number): MediaGalleryItem

Creates a k-media-gallery-item with the given attributes and adds it at index (the end by default). Returns the item.

removeItem(index: number): MediaGallery

Removes the item at index.

goTo(index: number): MediaGallery

Shows the item at index. Wraps around at either end.

next(): MediaGallery

Shows the next item, wrapping to the first after the last.

previous(): MediaGallery

Shows the previous item, wrapping to the last before the first.

open(): MediaGallery

Opens the fullscreen viewer.

close(): MediaGallery

Closes the fullscreen viewer.

toggle(): MediaGallery

Opens the fullscreen viewer if it is closed, closes it if it is open.

Events

change

Fired when the item shown changes. Event detail contains { index: number }.

fullscreenchange

Fired when the fullscreen viewer opens or closes. Event detail contains { fullscreen: boolean }.

Parts

gallery

The wrapper around the thumbnails and the stage.

stage

The large area showing the current item.

thumbs

The thumbnail strip.

CSS Variables

--thumb_size

The width and height of a thumbnail. Defaults to 4rem (3.5rem in the fullscreen viewer).

--thumb_gap

The space between thumbnails, and between the thumbnails and the stage. Defaults to 0.5rem.
