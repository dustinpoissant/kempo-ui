Built-in Controls

A pagination interface component that tracks the current page, calculates total pages from total-items and items-per-page, and emits page-change and items-per-page-change events when the pagination state changes. It does not manage or render the paginated content — it is a pure navigation interface. Place it beneath your content and listen for these events to know when to load new content.

Toolbar controls are slotted in — mix and match the built-in controls listed below, or write your own by extending PaginationControl. Use the controls attribute for preconfigured sets.

Basic Usage

Without any controls the component tracks state but renders nothing visible — useful when you supply your own UI.

<k-pagination total-items="100"></k-pagination>

With Controls

Slot any combination of built-in controls directly inside <k-pagination>. Import only what you need.

<k-pagination total-items="100">
  <k-pg-prev></k-pg-prev>
  <k-pg-page-info></k-pg-page-info>
  <k-pg-next></k-pg-next>
</k-pagination>

Simple Preconfigured

Use controls="simple" for a minimal previous / page-info / next toolbar. All required control modules are loaded automatically.

<k-pagination total-items="100" controls="simple"></k-pagination>

Full Preconfigured

Use controls="full" for a complete toolbar: first / previous / page-info / next / last + items-per-page selector.

<k-pagination total-items="100" controls="full"></k-pagination>

Items Per Page Options

Use the options attribute on <k-pg-items-per-page> to customize the available page-size choices. Pass a comma-separated list of numbers. Defaults to 10,25,50,100.

<k-pagination total-items='100'>
  <k-pg-prev></k-pg-prev>
  <k-pg-page-info></k-pg-page-info>
  <k-pg-next></k-pg-next>
  <k-pg-items-per-page options='5,10,20,50'></k-pg-items-per-page>
</k-pagination>

Live Demo

Listen for page-change to re-render content whenever the user navigates, and items-per-page-change to handle items-per-page updates. The event detail carries the full pagination state so your content layer knows exactly which slice to show.

<div id="pgDemoCards"></div>
<k-pagination id="pgLive" total-items="47" controls="full"></k-pagination>
<script>
  (function(){
    const pg = document.getElementById('pgLive');
    const container = document.getElementById('pgDemoCards');
    const renderCards = ({ currentPage, itemsPerPage, totalItems }) => {
      const start = (currentPage - 1) * itemsPerPage + 1;
      const end = Math.min(currentPage * itemsPerPage, totalItems);
      container.innerHTML = '';
      for(let i = start; i <= end; i++){
        const card = document.createElement('k-card');
        card.textContent = 'Item ' + i;
        container.appendChild(card);
      }
    };
    const handlePaginationChange = (e) => renderCards(e.detail);
    pg.addEventListener('page-change', handlePaginationChange);
    pg.addEventListener('items-per-page-change', handlePaginationChange);
    renderCards({ currentPage: 1, itemsPerPage: 10, totalItems: 47 });
  })();
</script>

Constructor

new Pagination();

Requirements

Import the main component. When using controls, import each control individually or use the controls attribute which auto-imports all control modules.

Properties

Property / Attribute Type Default Description
totalItems / total-items Number 0 Total number of items across all pages. Used to calculate totalPages.
itemsPerPage / items-per-page Number 10 Number of items shown per page. Changing this resets the current page to 1 and fires items-per-page-change.
controls String '' Preconfigured control set. One of 'simple' or 'full'. Auto-imports the required control modules.
page Number 1 The current page number. Reflects to the page attribute. Set directly (el.page = 3) or via attribute; value is automatically clamped to [1, totalPages].
totalPages (readonly) Number 1 Total number of pages, calculated as Math.ceil(totalItems / itemsPerPage). Read-only.

Methods

Method Description
nextPage() Advance to the next page. No-op when already on the last page.
previousPage() Go back to the previous page. No-op when already on the first page.

Events

Event Detail Description
page-change { currentPage, totalPages, itemsPerPage, totalItems } Fired when the current page changes (directly via .page, nextPage(), or previousPage()). Not fired when the page auto-resets due to configuration changes.
items-per-page-change { currentPage, itemsPerPage, totalPages, totalItems } Fired when itemsPerPage changes (which resets the current page to 1).

Built-in Controls

Each control is a separate custom element that finds its parent <k-pagination> and wires up automatically. Import only the controls you need.

Tag Import Description
<k-pg-first> paginationControls/FirstPage.js Jumps to page 1. Disabled when already on page 1.
<k-pg-prev> paginationControls/PrevPage.js Goes to the previous page. Disabled when on page 1.
<k-pg-page-info> paginationControls/PageInfo.js Displays “Page X of Y” text.
<k-pg-next> paginationControls/NextPage.js Goes to the next page. Disabled when on the last page.
<k-pg-last> paginationControls/LastPage.js Jumps to the last page. Disabled when already on the last page.
<k-pg-items-per-page> paginationControls/ItemsPerPage.js A select input for choosing items per page. Defaults to options 10, 25, 50, 100. Use the options attribute with a comma-separated list to customize (e.g. options="5,10,20"). Resets to page 1 on change.
<k-pg-goto-page> paginationControls/GotoPage.js A dropdown listing every page number. Selecting a value navigates directly to that page.
<k-pg-count> paginationControls/PageCount.js Displays the total page count as plain text. Pair with <k-pg-goto-page> to build a “Page X of Y” control.
