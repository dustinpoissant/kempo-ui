Audio picker

The Audio widget plays an audio file with a player. Its Audio URL setting is drawn by a picker, kept at PageBuilderFields.pickers.audio. By default it is a text box for the address. A site with a media library replaces it with a chooser that lists its audio files, and the builder uses that chooser for every Audio widget.

The Audio widget's settings

SettingMeaning
Audio URLThe address of an audio file. Uses the picker.
Controls, Play automatically, Loop, Muted, LoadingHow the audio plays.

The picker

A picker is a function that takes one object and returns a Lit template (the html tag from lit-all.min.js):

  • id: give the element this id. The field's label points at it.
  • value: the current address, or an empty string when there is none.
  • change(address, coalesce): sets the address. Pass coalesce as true while the person types, so that Undo does not record each key. Pass false (the default) for a choice, such as a file picked from a library.

Set the picker before the builder is opened.

Replacing it

mediaLibrary stands for the site's module, and its choose function calls back with the address of the audio file the person picked.

import PageBuilderFields from '/kempo-ui/src/components/pagebuilder/PageBuilderFields.js';
import {
  html
} from '/kempo-ui/src/lit-all.min.js';
import mediaLibrary from '/my-site/js/media-library.js';
PageBuilderFields.pickers.audio = ({
  id,
  value,
  change
}) => html`
  <button id="${id}" class="full" @click="${() => mediaLibrary.choose(url => change(url, false))}">${value || 'Choose an audio file'}</button>`;
