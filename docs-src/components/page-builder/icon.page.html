Icon picker

Icons are chosen with one picker, kept at PageBuilderFields.pickers.icon. By default it is the Icon Selector, which shows the site's icons and the brand icons for social links. A site that has its own icon source (an icon library, or an icon search that fetches icons from an API) replaces it, and every icon field in the builder uses that instead.

Where it is used

WidgetSetting
IconIcon. The Icon widget also has a Source (the address of any SVG file, used instead of the picked icon), a Direction or Rotation, and an Animation (spin, blink or pulse), as the Icon component does.
ButtonIcon, shown in front of the text
FileIcon, shown in front of the link text (a download icon by default)
Accordion sectionIcon, shown in front of the heading
TabIcon, shown in front of the tab name

The picker

A picker is a function that takes one object and returns a Lit template (the html tag from lit-all.min.js):

  • id: give the element this id. The field's label points at it.
  • value: the current icon. It is a kempo icon name, such as save. A custom SVG is src: followed by its path, such as src:/my-site/icons/logo.svg. An empty string means no icon.
  • change(value): sets the icon, with the same kind of value. A choice saves on its own, so there is no need for coalesce.

Set the picker before the builder is opened.

Adding icons to the default picker

The default picker keeps the site's icons from the icons folder. IconSelector.add(name, src) adds one more: with a src, it is a custom SVG, and without one, it is a name that the icons folder already has.

Replacing it

This picker is a site's own element, my-icon-search, which searches an icon API and fires change with the icon it picked.

import IconSelector from '/kempo-ui/src/components/IconSelector.js';
import PageBuilderFields from '/kempo-ui/src/components/pagebuilder/PageBuilderFields.js';
import {
  html
} from '/kempo-ui/src/lit-all.min.js';
IconSelector.add('logo', '/my-site/icons/logo.svg');
PageBuilderFields.pickers.icon = ({
  id,
  value,
  change
}) => html`
  <my-icon-search id="${id}" .value="${value}" @change="${event => change(event.detail.value)}"></my-icon-search>`;
