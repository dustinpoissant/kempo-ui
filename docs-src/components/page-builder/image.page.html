Image picker

The Image widget shows a picture. Its Image URL setting is drawn by a picker, which is a function kept at PageBuilderFields.pickers.image. By default it is a text box for the address. A site that has a media library replaces it with a chooser that lists the pictures on its server, and the builder uses that chooser wherever a picture is set.

The picker

A picker is a function that takes one object and returns a Lit template (the html tag from lit-all.min.js):

  • id: give the element this id. The field's label points at it.
  • value: the current address, or an empty string when there is none.
  • change(address, coalesce): sets the address. Pass coalesce as true while the person types, so that Undo does not record each key. Pass false (the default) for a choice, such as a picture picked from a library.

Set the picker before the builder is opened. A field is drawn when its widget is selected, so a picker set later applies from the next selection.

Replacing it

This picker opens the site's own library, and shows the chosen address. mediaLibrary stands for the site's module, and its choose function calls back with the address of the picture the person picked.

import PageBuilderFields from '/kempo-ui/src/components/pagebuilder/PageBuilderFields.js';
import {
  html
} from '/kempo-ui/src/lit-all.min.js';
import mediaLibrary from '/my-site/js/media-library.js';
PageBuilderFields.pickers.image = ({
  id,
  value,
  change
}) => html`
  <button id="${id}" class="full" @click="${() => mediaLibrary.choose(url => change(url, false))}">${value || 'Choose a picture'}</button>`;
