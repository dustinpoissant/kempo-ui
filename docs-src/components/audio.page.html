An <audio> wrapper with no native controls, the sound-only sibling of Video. It uses the same slotted kc-vid-* controls (play and pause, seek, time, volume, speed, loop, skip), so a toolbar is built the same way, with the controls attribute or by slotting controls in.

Basic Usage

With no controls and nothing slotted in, k-audio draws nothing: drive it from your own buttons with play() and pause(). Add controls="normal" for a toolbar.

<k-audio src="/media/vibedepot-lofi-hip-hop.mp3" controls="normal"></k-audio>

Preconfigured Controls

controls takes minimal (play and pause, time, seek, duration), normal (those, plus volume and repeat) or full (normal, plus speed, skip back and forward, and download). none or no value draws no toolbar.

<k-audio src="/media/vibedepot-sweet.mp3" controls="minimal"></k-audio>
 
<k-audio src="/media/vibedepot-fashion.mp3" controls="normal"></k-audio>
 
<k-audio src="/media/ketsa-black-screen.mp3" controls="full"></k-audio>

Manual Controls

Slot any controls inside the element, and they replace the preset. Wrap them in a <k-control-bar> so they stay on one row and collapse into a “more” menu when the player is narrow, instead of wrapping. Put a control in the center or right slot to place it, give it a priority to keep it in the bar longer, and add no-collapse so it never moves into the menu (the seek bar here just gets shorter).

<k-audio src="../media/vibedepot-lofi-hip-hop.mp3">
  <k-control-bar>
    <kc-media-play-pause priority="10"></kc-media-play-pause>
    <kc-media-time slot="center" priority="1"></kc-media-time>
    <kc-media-seek slot="center" no-collapse soft-min-width="8rem"></kc-media-seek>
    <kc-media-duration slot="center" priority="1"></kc-media-duration>
    <kc-media-volume slot="right"></kc-media-volume>
    <kc-media-speed slot="right"></kc-media-speed>
  </k-control-bar>
</k-audio>

Resume Playback Position

Give the element a persistent-id and its position is kept in the browser session, so a reload carries on from where it was. The position is forgotten when the sound ends.

<k-audio src="/media/vibedepot-sweet.mp3" controls="normal" persistent-id="sweet"></k-audio>

Top and Bottom Slots

The toolbar has three slots. The default slot holds the controls, the top slot sits above them and the bottom slot sits below. Slot anything into top or bottom with slot="top" or slot="bottom". A controls preset still draws its controls when only the top or bottom slot is used.

kc-media-metadata shows the track's artist, title, album and year as a line separated by dots. It scrolls only when the text is too long to fit. Set scroll-mode="always" to scroll it all the time. Set those on the element with artist, track-title, album and year.

<k-audio src="/media/ketsa-black-screen.mp3" controls="normal" artist="Ketsa" track-title="Black Screen">
  <kc-media-metadata slot="top"></kc-media-metadata>
</k-audio>
 
<k-audio src="/media/vibedepot-lofi-hip-hop.mp3" controls="minimal" artist="VibeDepot" track-title="lofi hip-hop" album="Lofi" year="2026">
  <kc-media-metadata slot="bottom"></kc-media-metadata>
</k-audio>

Metadata From the File

The element reads the title, artist, album and year stored in the audio file (ID3 tags, or MP4 tags on an M4A) and kc-media-metadata shows them, so a tagged file needs no attributes. Only the start and end of the file are requested, and the server needs to support range requests. Set track-title, artist, album or year on the element (or on a kc-audio-track) to replace or add to what the file says; the file only fills the fields left empty. A file with no tags shows nothing. Add read-metadata="false" to skip reading the file.

<k-audio src="../media/vibedepot-tagged.mp3" controls="normal">
  <kc-media-metadata slot="top"></kc-media-metadata>
</k-audio>
 
<k-audio src="../media/vibedepot-tagged.mp3" controls="normal" artist="Remixed by me">
  <kc-media-metadata slot="top"></kc-media-metadata>
</k-audio>

Scrolling

kc-media-metadata scrolls only when its text is wider than the control. That is the default, scroll-mode="auto". Set scroll-mode="always" to scroll it all the time, like a marquee. Users who prefer reduced motion never see it scroll.

The first player below is narrowed so its text doesn't fit, and scrolls on its own. The second has a short title and scrolls because of scroll-mode="always".

<k-audio src="/media/vibedepot-lofi-hip-hop.mp3" controls="minimal" artist="VibeDepot" track-title="lofi hip-hop" album="Lofi" year="2026" style="max-width: 12rem;">
  <kc-media-metadata slot="top"></kc-media-metadata>
</k-audio>
 
<k-audio src="/media/vibedepot-sweet.mp3" controls="minimal" artist="VibeDepot" track-title="sweet">
  <kc-media-metadata slot="top" scroll-mode="always"></kc-media-metadata>
</k-audio>

Media Link

kc-media-link shows the full URL of the media as a link that opens it in a new tab. It follows src, so it updates when the source changes.

<k-audio src="/media/vibedepot-sweet.mp3" controls="minimal">
  <kc-media-link slot="bottom"></kc-media-link>
</k-audio>

Download

Add kc-media-download to the toolbar to let listeners save the file, or call download() yourself. Set download-name to choose the saved file's name.

<k-audio src="/media/ketsa-black-screen.mp3" controls="minimal" download-name="Black Screen - Ketsa.mp3">
  <kc-media-download slot="bottom"></kc-media-download>
</k-audio>

Playlists

List tracks as kc-audio-track children of k-audio. The first track is loaded when the page opens, and the player moves to the next track when one ends. kc-audio-previous and kc-audio-next move through the list, and kc-audio-playlist lists every track so a listener can pick one. Drag a row in kc-audio-playlist to reorder the playlist. Track details come from the same attributes as the element itself: artist, track-title, album, year and download-name.

By default the player stops at the end of the playlist. Set playlist-loop, or press kc-audio-loop, to go back to the first track after the last one, and to the last track when Previous is pressed on the first.

<k-audio playlist-loop>
  <kc-audio-playlist slot="top"></kc-audio-playlist>
  <kc-audio-previous></kc-audio-previous>
  <kc-media-play-pause></kc-media-play-pause>
  <kc-audio-next></kc-audio-next>
  <kc-media-seek></kc-media-seek>
  <kc-audio-loop></kc-audio-loop>
  <kc-audio-shuffle></kc-audio-shuffle>
  <kc-audio-track src="/media/vibedepot-lofi-hip-hop.mp3" artist="VibeDepot" track-title="lofi hip-hop" album="Lofi" year="2026"></kc-audio-track>
  <kc-audio-track src="/media/vibedepot-sweet.mp3" artist="VibeDepot" track-title="sweet"></kc-audio-track>
  <kc-audio-track src="/media/vibedepot-fashion.mp3" artist="VibeDepot" track-title="fashion"></kc-audio-track>
  <kc-audio-track src="/media/ketsa-black-screen.mp3" artist="Ketsa" track-title="Black Screen"></kc-audio-track>
</k-audio>

Methods

Each returns the element, so calls chain.

Method
play(), pause(), togglePlayPause()Start, stop or switch.
seek(time), skip(seconds)Go to a time, or move by an amount (negative goes back).
setVolume(volume), mute(), unmute(), toggleMute()Volume and muting.
setPlaybackRate(rate), toggleLoop()Speed and looping.
playTrack(index), selectTrack(index)Load track index from the kc-audio-track children, and play it (playTrack only).
toggleShuffle()Shuffles the tracks, animating the rows into their new places, and remembers the order. Toggled off, it restores that order. Moving a track by hand clears the saved order and turns shuffle off. The current track stays selected.
reorderTracks(order)Reorders the kc-audio-track children to the given list of current indexes, and keeps the current track selected. Dragging in kc-audio-playlist calls this.
previousTrack(), nextTrack(), togglePlaylistLoop()Move through the playlist, or switch looping the whole playlist on and off.
download()Downloads src using a temporary anchor, named via downloadName when set.

Events

These bubble from the element: play, pause, timeupdate, loadedmetadata, durationchange, canplay, waiting, seeking, seeked, ended, volumechange, ratechange and error, plus loop-changed with { loop }, metadata-changed when the artist, title, album or year changes, src-changed when src changes, track-changed when a playlist track is selected, playlist-changed when the playlist's tracks change, and playlist-loop-changed when looping the playlist is switched on or off, playlist-shuffling just before a shuffle or restore, and shuffle-changed when shuffle is switched on or off.
