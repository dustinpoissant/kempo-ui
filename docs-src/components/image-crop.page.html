Basic Usage

With no attributes the component is a free-form cropper. It shows an Upload Image button and a drop zone; once an image is chosen, drag the crop box to move it and drag any of its handles to resize it to any aspect ratio. The size under the image is the size of the cropped output.

<k-image-crop></k-image-crop>

Aspect Ratio and Maximum Size

Set aspect-ratio to lock the crop box to a ratio (1, 16/9, 4:3, 0.75...). Set max-width and/or max-height to cap the output size. A crop larger than the limits is scaled down (keeping its ratio), a smaller crop is never scaled up. This is the profile photo case: a square crop of any uploaded image, output at no more than 512×512.

<k-image-crop aspect-ratio="1" max-width="512" max-height="512"></k-image-crop>

Initial Image

Set src to start with an image already loaded, for example to re-crop something already uploaded. Cross-origin images must be served with CORS headers, otherwise the browser will not let the canvas export the crop.

<k-image-crop src="../media/corvette.jpg" aspect-ratio="16/9" max-width="800"></k-image-crop>

JavaScript Usage

Get the cropped result with toBlob(), toFile(), toDataURL() or getCroppedCanvas(). The change event fires when an image is loaded and whenever the crop is adjusted, so you can keep a live preview. Use crop to read or set the crop rectangle in source-image pixels.

<k-image-crop id="jsCrop" src="../media/gtr.jpg" aspect-ratio="1" max-width="256"></k-image-crop>
<div class="mt">
  <img id="jsPreview" alt="Crop preview" style="max-width:128px;vertical-align:middle" />
  <button id="jsDownload" class="ml">Download</button>
  <button id="jsTopLeft" class="ml">Crop top-left</button>
</div>
<p>Crop: <code id="jsInfo"></code></p>
<script>
  const $crop = document.getElementById('jsCrop');
  const $preview = document.getElementById('jsPreview');
  const $info = document.getElementById('jsInfo');
  $crop.addEventListener('change', (e) => {
    $preview.src = $crop.toDataURL() || '';
    $info.textContent = JSON.stringify(e.detail.crop) + ' -> ' + e.detail.width + 'x' + e.detail.height;
  });
  document.getElementById('jsDownload').addEventListener('click', async () => {
    const file = await $crop.toFile('cropped.png');
    if (!file) return;
    const a = document.createElement('a');
    a.href = URL.createObjectURL(file);
    a.download = file.name;
    a.click();
  });
  document.getElementById('jsTopLeft').addEventListener('click', () => {
    $crop.crop = {
      x: 0,
      y: 0,
      width: 600,
      height: 600
    };
  });
</script>

Form Integration

ImageCrop is form-associated. With a name, the cropped image is submitted with the form as a File, exactly like <input type="file">, so it works with FormData, fetch and a normal multipart/form-data submit. required blocks submission until an image is chosen, and resetting the form clears the image (or restores src). The file is named after the original upload.

<form id="avatarForm">
  <label>Username <input name="username" value="dustin" /></label>
  <k-image-crop name="avatar" aspect-ratio="1" max-width="512" max-height="512" type="image/jpeg" required></k-image-crop>
  <div class="mt">
    <button type="submit" class="mr">Submit</button>
    <button type="reset">Reset</button>
  </div>
</form>
<p>Submitted: <span id="avatarResult"></span></p>
<script>
  document.getElementById('avatarForm').addEventListener('submit', (e) => {
    e.preventDefault();
    const avatar = new FormData(e.target).get('avatar');
    document.getElementById('avatarResult').textContent = avatar.name + ' (' + avatar.type + ', ' + avatar.size + ' bytes)';
  });
</script>

Output Format

The output is PNG by default. Set type to image/jpeg or image/webp and quality (0-1) to trade size for fidelity. JPEG has no transparency, so transparent areas are filled white.

<k-image-crop id="fmtCrop" src="../media/nsx.jpg" type="image/webp" quality="0.6" max-width="400"></k-image-crop>
<p>Output: <span id="fmtInfo"></span></p>
<script>
  const $fmt = document.getElementById('fmtCrop');
  $fmt.addEventListener('change', async () => {
    const blob = await $fmt.toBlob();
    document.getElementById('fmtInfo').textContent = blob.type + ', ' + blob.size + ' bytes';
  });
</script>

Disabled

A disabled cropper cannot be changed by the user.

<k-image-crop src="../media/civic.jpg" aspect-ratio="4/3" disabled></k-image-crop>

Custom Styles

Override --crop_color (crop box and drop zone highlight), --crop_handle_size and --crop_max_height (maximum displayed image height, in pixels, unitless) to restyle the widget. --crop_max_height only affects the on-screen editor, never the output size.

<k-image-crop src="../media/evo.jpg" style="
    --crop_color: var(--c_danger);
    --crop_handle_size: 1.25rem;
    --crop_max_height: 240;
  "></k-image-crop>

JavaScript Reference

Constructor

new ImageCrop();

Requirements

ImageCrop is a custom element with no dependencies beyond the Kempo-UI library. The image is drawn on a <canvas>; the output is rendered on a separate offscreen canvas, so it is always exported at the final size from the original full-resolution image.

Properties

Property Type Default Description
src String '' URL of an image to load. Changing it loads the new image. Must be same-origin or served with CORS headers.
name String '' Form field name. The cropped image is submitted as a File under this name.
aspectRatio String '' Attribute aspect-ratio. Locks the crop box to a ratio: 1, 1.5, 16/9 or 16:9. Empty (or free) allows any ratio.
maxWidth Number 0 Attribute max-width. Maximum output width in pixels. 0 means no limit.
maxHeight Number 0 Attribute max-height. Maximum output height in pixels. 0 means no limit.
type String 'image/png' Output MIME type: image/png, image/jpeg or image/webp.
quality Number 0.92 Output quality from 0 to 1, used by image/jpeg and image/webp.
label String 'Upload Image' Text of the upload button.
placeholder String 'or drop an image here' Hint text shown beside the upload button.
disabled Boolean false Prevents changing the image or crop. Also set automatically by a disabled <fieldset>.
required Boolean false The form cannot be submitted until an image is chosen.
hasImage Boolean (read-only) true once an image is loaded.
crop Object null The crop rectangle { x, y, width, height } in source-image pixels. Settable; the value is clamped to the image and the aspect ratio.
outputSize Object (read-only) null The { width, height } of the exported image after max-width/max-height scaling.

Methods

Method Description
loadImage(source) Loads a File, Blob or URL string. Returns a Promise resolving true on success.
clear() Removes the image.
openFilePicker() Opens the browser file chooser.
getCroppedCanvas() Returns a new <canvas> containing the cropped, scaled image, or null with no image.
toBlob(type?, quality?) Promise resolving a Blob of the output (or null). Defaults to type and quality.
toFile(fileName?) Promise resolving a File. The default name is the original name plus -cropped and the right extension.
toDataURL(type?, quality?) Returns a data URL of the output, or null.

Events

Event Detail Description
change { crop, width, height } Fired when an image is loaded or cleared and after each crop adjustment (on release of a drag, not during it). width/height are the output size.
load { width, height } Fired when an image has loaded; detail is the source image size.
error { message } Fired when a chosen or dropped file is not a loadable image.

CSS Custom Properties

Property Default Description
--crop_color var(--c_primary) Crop box border, handle border and drop-zone highlight.
--crop_handle_size 0.875rem Diameter of the resize handles.
--crop_max_height 480 Maximum height of the editor image in pixels (unitless).
