Control Group (<k-control-group>)
Import: import 'kempo-ui/src/components/ControlGroup.js';
Docs: https://dustinpoissant.github.io/kempo-ui/components/control-group.html

Groups toolbar controls visually

Details:
- strips child borders/radius/margin and adds right-side separators via `::slotted(*)`
- auto-hides when all children are hidden
- used internally by CodeEditor, HtmlEditor, and other toolbar-based components
