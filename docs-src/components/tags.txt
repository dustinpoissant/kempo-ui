Tags (<k-tags> <k-tag>)
Import: import 'kempo-ui/src/components/Tags.js';
Docs: https://dustinpoissant.github.io/kempo-ui/components/tags.html

Tag input

Details:
- add/remove tags
- inline autocomplete via `getSuggestions`
- fires `change`
- form-associated via `name`: submits the comma-separated tags; `required` needs at least one tag; a form reset returns to the starting tags
- `readonly` (Boolean): tags are shown and submitted; tags cannot be added or removed
