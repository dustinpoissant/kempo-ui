Aside (<k-aside> <k-aside-item> <k-aside-label> <k-aside-menu> <k-aside-spacer> <k-aside-toggle>)
Import: import 'kempo-ui/src/components/Aside.js';
Docs: https://dustinpoissant.github.io/kempo-ui/components/aside.html

Sidebar/drawer

Details:
- `main="push"` or `main="overlay"`, `side="left|right"`
- `mobile-main="overlay"` (or `push`) sets the `main` used at or below 768px wide, e.g. `main="push" mobile-main="overlay"`; the effective value is reflected in `layout`
- `push-from-offscreen="collapsed"` (optional): when the layout becomes `push` while offscreen, the aside takes this state so its rail can reopen it
- `overlay-from-collapsed="offscreen"` (optional): when the layout becomes `overlay` while collapsed, the aside takes this state
- in the overlay layout the header toggle is an X that hides the aside; in push it is the arrow that collapses to the rail

- `<k-aside-item group="Name">` auto-wraps items sharing a group (2+, `group-min`) in a menu, icon from `group-icons` JSON / `group-icon` / folder
