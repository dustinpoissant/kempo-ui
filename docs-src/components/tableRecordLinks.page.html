A record can carry a _url property that points to a page for that record. It is not rendered as a column, so the table only shows the fields you actually display. The _url value is available to anything that reads the record, such as the Row Controls kc-tc-open button.

Open on Row Click

Add open-on-click to the table and clicking a row with a _url opens it, in the current tab. Clicks on row controls and editable cells do not trigger it. Add row-target="_blank" alongside it to open the row in a new tab instead.

<k-table id="rowClickExample" open-on-click row-target="_blank"></k-table>
<script type="module">
  await window.customElements.whenDefined('k-table');
  document.getElementById('rowClickExample').setRecords([{
    name: 'Kempo UI',
    _url: 'https://github.com/dustinpoissant/kempo-ui'
  }, {
    name: 'Kempo CSS',
    _url: 'https://github.com/dustinpoissant/kempo-css'
  }]);
</script>
