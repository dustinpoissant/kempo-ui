Dual Side Panels

This page demonstrates two side panels working simultaneously - one on the left and one on the right.

Try toggling each panel independently using the arrow buttons.

Features

  • Left panel defaults to left side
  • Right panel uses side="right" attribute
  • Both panels can be collapsed/expanded independently
  • Main content automatically adjusts margins for both panels
  • Toggle arrows point correctly for each side
