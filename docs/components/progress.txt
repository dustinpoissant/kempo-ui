Progress (<k-progress>)
Import: import 'kempo-ui/src/components/Progress.js';
Docs: https://dustinpoissant.github.io/kempo-ui/components/progress.html

Progress bar.

Attributes:
- percentage: the size of the bar, a number from 0 to 100 (default 25). Several bars can share one track: separate the numbers with "|", for example "30|20".
- offset: where a bar starts, as a percentage; separate several with "|".
- color: any CSS color (default the primary color); separate several with "|", one per bar.
- label (Boolean): shows the percentage as text on the bar.
- indeterminate: an animated bar for when the amount is not known.
