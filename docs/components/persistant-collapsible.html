Basic Usage

The k-p-collapsible component extends the regular k-collapsible with automatic state persistence using localStorage. The component remembers its opened/closed state and restores it when the page is reloaded or reopened.

Important: The component requires an id attribute to function properly, as this is used as the localStorage key.

<k-p-collapsible id="example1">
  <span slot="label">Persistent Section</span>
  <p class="p">This content's visibility state will be remembered across page reloads.</p>
</k-p-collapsible>
Persistent Section

This content's visibility state will be remembered across page reloads. Try expanding/collapsing it and then refreshing the page.

Custom Label

You can customize the label using the label slot, just like with regular collapsible components.

<k-p-collapsible id="example2">
  <h4 slot="label" class="m0">Settings</h4>
  <div class="p">
    <label>
      <input type="checkbox"> Enable notifications
    </label>
    <label>
      <input type="checkbox"> Auto-save
    </label>
  </div>
</k-p-collapsible>

Custom Icon

Override the default chevron icon using the icon slot.

<k-p-collapsible id="example3">
  <span slot="label">Advanced Options</span>
  <k-icon name="settings" slot="icon"></k-icon>
  <p class="p">Advanced configuration options with persistent state.</p>
</k-p-collapsible>

JavaScript Reference

Constructor

Extends Collapsible
new PersistantCollapsible()

Creates a new PersistantCollapsible instance. The constructor takes no parameters.

Requirements

  • Collapsible

Attributes

Inherits all attributes from Collapsible:

opened: boolean

Whether the collapsible is opened. This state is automatically persisted to localStorage.

id: string (Required)

A unique identifier for the component. This is used as the localStorage key and must be present for persistence to work.

Methods

Inherits all methods from Collapsible:

open(): void

Opens the collapsible and saves the state to localStorage.

close(): void

Closes the collapsible and saves the state to localStorage.

toggle(): void

Toggles the collapsible open or closed and saves the state to localStorage.

Storage Behavior

The component automatically:

  • Loads its state from localStorage when connected to the DOM
  • Saves its state to localStorage whenever the opened property changes
  • Synchronizes state across browser tabs using storage events
  • Uses the storage key format: PersistantCollapsible-{id}
