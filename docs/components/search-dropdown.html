A search box that shows what was found in a popover under it, as the person types. It does not know where results come from: when typing pauses it fires search, and you answer with setResults(). That is what makes it work with any search, such as a site's own search API. Use it where the result is somewhere to go (a page, a record); to pick a value for a form field use Combobox, which keeps the option chosen.

Basic Usage

Listen for search and call setResults() with a list of results. Each result has a title and, usually, a url (it is drawn as a link, so it can be opened in a new tab) and a description. The box shows a spinner from the moment typing pauses until you answer, and setError() shows a message instead. Nothing is searched until min-length characters (2) are typed.

<k-search-dropdown id="basicDropdown" placeholder="Search the docs..."></k-search-dropdown>
 
const dropdown = document.querySelector('#basicDropdown');
dropdown.addEventListener('search', async e => {
  const response = await fetch('/api/search?q=' + encodeURIComponent(e.detail.value));
  if(!response.ok) return dropdown.setError('The search failed.');
  dropdown.setResults(await response.json());
});
dropdown.addEventListener('select', e => {
  console.log('Chose', e.detail.result.title);
});

Groups

Results that share a group are listed under a heading. A heading is drawn where the group changes from one result to the next, so send the results grouped.

<k-search-dropdown id="groupDropdown" placeholder="Search pages and people..."></k-search-dropdown>
 
dropdown.setResults([
  { group: 'Pages', title: 'Pricing', url: '/pricing', description: 'What our plans cost' },
  { group: 'Pages', title: 'About us', url: '/about' },
  { group: 'People', title: 'Ada Lovelace', description: 'ada@example.com' }
]);

In a Form

The search dropdown is form-associated: its text is submitted under name. Pressing Enter with no result chosen submits the form it is in, so the same box can go straight to a full results page (<form action="/search">), and still show a quick preview as you type. required, a form reset and a disabled <fieldset> work as for the other form components.

<form id="searchForm" action="/search">
  <k-search-dropdown name="q" placeholder="Press Enter for all results..."></k-search-dropdown>
</form>

In a Nav

It sizes to the width you give it, and the popover is at least 22rem wide (--min-width) and opens in the top layer, so a narrow box in a nav still shows full results and is never clipped by the nav. It flips to stay on screen near the edge of the window.

<k-nav>
  <a href="/" no-collapse>Home</a>
  <k-search-dropdown id="navDropdown" placeholder="Search" style="width: 10rem"></k-search-dropdown>
</k-nav>

Read-only

The readonly attribute shows the text and keeps it in the form, but the person cannot type or open the results. It stays in the tab order.

<k-search-dropdown name="q" readonly value="pricing"></k-search-dropdown>

Results

setResults() takes a list of objects. Anything else in the list is ignored.

FieldTypeDescription
titleStringThe main text. Falls back to url, then “Untitled”.
urlStringWhere the result goes. It is drawn as a link and followed on Enter unless select is cancelled. Without one the result is only reported through select. Only pass addresses you trust: the value is used as a link as it is.
descriptionStringA line of secondary text under the title.
groupStringA heading drawn where it changes from the result before.

Your own fields can ride along; select gives the whole object back.

Methods

MethodDescription
setResults(results)Shows the results, ends searching and opens the list if it is closed. An empty list shows no-results-message. Returns this.
setError(message)Shows an error line instead of results and ends searching. Returns this.
clear()Empties the box and the results and closes the list. Returns this.
focus()Focuses the box.

Events

EventDetailDescription
search{ value: String }Typing paused for debounce-ms and at least min-length characters are typed. value is the trimmed text. Answer it with setResults() or setError(). Only the last text typed fires, so an earlier search never needs cancelling here, but your own request for an earlier text can still arrive late: ignore it if the text has changed.
select{ result: Object }A result was clicked or chosen with Enter. Cancelable: preventDefault() stops the link or navigation, for a result you open yourself.

The native input event from the box also bubbles out, so you can follow every keystroke.
