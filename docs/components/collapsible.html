Description

The Collapsible component provides a way to show/hide content with a clickable label header. It features a rotating chevron icon and smooth transitions. The component extends the ShadowComponent class and supports customizable labels and icons through slots.

Basic Usage

Use the collapsible component to create expandable content sections. Click the label to toggle the content visibility.

<k-collapsible>
  <span slot="label">Click to expand</span>
  <p>This content can be collapsed or expanded.</p>
  <p>Add any content here that you want to show/hide.</p>
</k-collapsible>

Default Open

Set the opened attribute to have the collapsible start in an expanded state.

<k-collapsible opened="true">
  <span slot="label">Already expanded</span>
  <p>This collapsible starts in an open state.</p>
</k-collapsible>
Already expanded

This collapsible starts in an open state.

Custom Label

You can put any content in the label slot, including formatted text, icons, or even other components.

<k-collapsible>
  <div slot="label">
    <strong>Advanced Settings</strong>
    <small class="opacity-50 ml">(Optional)</small>
  </div>
  <p>Configure advanced options here.</p>
</k-collapsible>
Advanced Settings (Optional)

Configure advanced options here.

Custom Icon

Replace the default chevron icon with your own content using the labelIcon slot.

<k-collapsible>
  <span slot="label">Custom Icon</span>
  <span slot="labelIcon">▼</span>
  <p>Using a custom arrow icon.</p>
</k-collapsible>
Custom Icon ▼

Using a custom arrow icon.

JavaScript Reference

Constructor

Extends ShadowComponent
new Collapsible()

Requirements

  • ShadowComponent
  • Icon

Properties

opened: boolean

Gets or sets whether the collapsible is currently expanded. Changing this property will trigger the appropriate events and visual state changes. Syncs to opened attribute. Default value is false.

Methods

open(): void

Expands the collapsible to show its content. Sets opened to true.

close(): void

Collapses the collapsible to hide its content. Sets opened to false.

toggle(): void

Toggles the collapsible state (expands if collapsed, collapses if expanded). Dispatches an openedtoggled event.

Events

openedchanged

Fired when the opened state changes. The event detail contains the string "open" or "close".

open

Fired when the collapsible is expanded.

close

Fired when the collapsible is collapsed.

openedtoggled

Fired when the toggle() method is called (typically when the label is clicked).

Slots

Default Slot

The main content area that can be collapsed or expanded.

label

The clickable label content. This is what users click to toggle the collapsible state.

labelIcon

Custom content for the toggle icon. Defaults to a right-pointing chevron that rotates when expanded. The icon automatically gets hover effects and rotation animations.
