Basic Usage

The field looks like an input: the icon is on the left and its name is on the right. Clicking it opens a dialog with every icon. Click an icon to select it, then choose Choose Icon to keep it, or Cancel to leave the value as it was.

<k-icon-selector></k-icon-selector>

Value By Default

Set the value attribute to the icon's name, without the .svg extension. That icon is shown and highlighted when the dialog opens.

<k-icon-selector value="star"></k-icon-selector>

Dialog Title

The dialog-title attribute sets the heading of the dialog. It defaults to Choose an Icon.

<k-icon-selector value="star" dialog-title="Pick a Status Icon"></k-icon-selector>

Placeholder

The placeholder attribute is the text shown in the field when no icon is selected. It defaults to Choose an Icon.

<k-icon-selector placeholder="Pick a menu icon"></k-icon-selector>

Icon Only

The icon-only attribute shows just the icon, without its name. The field is inline, so it sits in a line of text or a toolbar. The name stays available to screen readers and as the tooltip.

<k-icon-selector icon-only value="star"></k-icon-selector>

Limiting the Icons

The icons attribute is a comma-separated list of the icon names the person can choose from. Spaces around each name are trimmed. Without it, the dialog offers every icon in IconSelector.icons.

<k-icon-selector value="save" icons="save, check, close, star, warning"></k-icon-selector>

Custom Icons

Icons outside the standard icons directory are added with IconSelector.add(name, src). The src is the path to the SVG file. It is optional: without it, name is treated as a standard icon. An added icon is offered in every Icon Selector, in addition to the icons attribute or the default list. Its value is src: followed by the path, so a custom icon submits as, for example, src:/media/hexagon.svg. Values starting with src: always mean a path, which lets the server tell a path from a name.

import IconSelector from 'kempo-ui/src/components/IconSelector.js';
IconSelector.add('hexagon', '/media/hexagon.svg');
 
<k-icon-selector value="src:/media/hexagon.svg"></k-icon-selector>

Form Integration

Icon Selector is form-associated. Set a name attribute and the icon's name submits with the rest of the form. A custom icon submits src: followed by its path, as the second example shows.

<form id="iconForm">
  <label for="menuIcon">Menu icon</label>
  <k-icon-selector id="menuIcon" name="menuIcon" value="menu"></k-icon-selector>
  <button type="submit" class="mt primary">Save</button>
</form>
<p>Submitted: <span id="result"></span></p>
<script>
  document.getElementById('iconForm').addEventListener('submit', (e) => {
    e.preventDefault();
    const formData = new FormData(e.target);
    document.getElementById('result').textContent = formData.get('menuIcon');
  });
</script>

Listening for Changes

The change event fires when the person chooses an icon with Choose Icon. Cancelling does not fire it. The detail holds the new value.

<k-icon-selector id="picker" value="star"></k-icon-selector>
<p>Chosen: <span id="chosen">star</span></p>
<script>
  document.getElementById('picker').addEventListener('change', (event) => {
    document.getElementById('chosen').textContent = event.detail.value;
  });
</script>

Chosen: star

Auto Choose

The auto-choose attribute chooses an icon as soon as it is clicked. The dialog closes, change fires, and there is no Choose Icon button. Cancel stays and leaves the value as it was.

<k-icon-selector auto-choose value="star"></k-icon-selector>

Disabled

The disabled attribute stops the dialog from opening, so the icon cannot be changed, and leaves the value out of the form. An icon selector inside a disabled <fieldset> is disabled too. It appears at 50% opacity.

<k-icon-selector name="icon" disabled value="star"></k-icon-selector>

Read-only

The readonly attribute shows the chosen icon and keeps it in the form, but the user cannot open the dialog to change it.

<k-icon-selector name="icon" readonly value="star"></k-icon-selector>

JavaScript Reference

Constructor

Extends ShadowComponent
new IconSelector()

Requirements

  • ShadowComponent
  • Dialog, Filter List and Icon, which are imported by the component.

Attributes

Attribute Type Default Description
value String "" The chosen icon's name, without the extension. For a custom icon, src: followed by the path to its SVG. Reflects to the attribute.
name String "" The field name used when the surrounding form submits. Reflects to the attribute.
icons String All icons in IconSelector.icons A comma-separated list of the icon names to choose from. Each name is trimmed of spaces.
dialog-title String Choose an Icon The heading of the dialog.
placeholder String Choose an Icon The text shown in the field when no icon is selected.
icon-only Boolean Off Shows only the icon, not its name, and makes the field inline. The name is kept as its label and tooltip.
allow-clear Boolean Off Changes the dialog's Cancel button to Clear. Clicking it empties the value and fires change.
auto-choose Boolean Off Chooses an icon as soon as it is clicked, closing the dialog. The Choose Icon button is removed; Cancel stays.
disabled Boolean Off Stops the dialog from opening, so the icon cannot be changed. The value is left out of the form. Also set automatically by a disabled <fieldset>. The selector appears at 50% opacity.
readonly Boolean Off Shows the chosen icon and still submits it with the form, but the dialog cannot be opened to change it. The selector appears at 75% opacity.

Events

Event Detail Description
change { value: String } Fired when the person chooses an icon with Choose Icon. Not fired when the dialog is cancelled or when the value is set in code.

Static Members

IconSelector.icons: string[]

The default list of icon names, used when the icons attribute is not set. It holds every icon in the standard icons directory. Change the array to change the default list for every Icon Selector.

IconSelector.add(name: string, src: string): void

Adds an icon that every Icon Selector offers, in addition to its icons attribute or the default list. Pass src for an SVG outside the standard icons directory. An icon added with the same name as an existing one replaces it.
