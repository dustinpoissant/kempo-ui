Description

A widget that allows a single panel of content to be opened and closed.

Basic Usage

<k-accordion>
<k-accordion-header for-panel="panel1">Panel 1</k-accordion-header>
<k-accordion-panel name="panel1">
  <p class="m">Panel 1 content</p>
</k-accordion-panel>
<k-accordion-header for-panel="panel2">Panel 2</k-accordion-header>
<k-accordion-panel name="panel2">
  <p class="m">Panel 2 content</p>
</k-accordion-panel>
<k-accordion-header for-panel="panel3">Panel 3</k-accordion-header>
<k-accordion-panel name="panel3">
  <p class="m">Panel 3 content</p>
</k-accordion-panel>
</k-accordion>

Default Open Panel

You can have a panel open by default by setting the active attribute to true on both the header and the panel.

<k-accordion>
  <k-accordion-header for-panel="panel1" active="true">Panel 1</k-accordion-header>
  <k-accordion-panel name="panel1" active="true">
    <p class="m">Panel 1 content</p>
  </k-accordion-panel>
  <k-accordion-header for-panel="panel2">Panel 2</k-accordion-header>
  <k-accordion-panel name="panel2">
    <p class="m">Panel 2 content</p>
  </k-accordion-panel>
  <k-accordion-header for-panel="panel3">Panel 3</k-accordion-header>
  <k-accordion-panel name="panel3">
    <p class="m">Panel 3 content</p>
  </k-accordion-panel>
</k-accordion>

JavaScript Reference

Constructor

Extends ShadowComponent
new Accordion()

Requirements

  • ShadowComponent

Attributes

AccordionHeader

for-panel: string

Specifies the panel name that this header controls. This attribute reflects the forPanel property.

active: boolean

Indicates whether this header is currently active (its associated panel is open). Automatically managed by the accordion.

AccordionPanel

name: string

Unique identifier for this panel. Must match the for-panel attribute of its associated header.

active: boolean

Indicates whether this panel is currently open. Automatically managed by the accordion.

transitioning: boolean

Indicates whether this panel is currently animating (opening or closing). Automatically managed during transitions.

Properties

Accordion (Main Component)

activeHeader: HTMLElement | null

Returns the currently active header element, or null if no panel is open.

activePanel: HTMLElement | null

Returns the currently active panel element, or null if no panel is open.

AccordionHeader

forPanel: string

The panel name that this header controls. Reflects to the for-panel attribute.

active: boolean

Whether this header is currently active. Reflects to the active attribute.

accordion: Accordion | null

Returns the parent accordion component, or null if not inside an accordion.

AccordionPanel

name: string

Unique identifier for this panel. Reflects to the name attribute.

active: boolean

Whether this panel is currently open. Reflects to the active attribute.

transitioning: boolean

Whether this panel is currently animating. Reflects to the transitioning attribute.

accordion: Accordion | null

Returns the parent accordion component, or null if not inside an accordion.

Methods

Accordion (Main Component)

getHeader(panelName): HTMLElement | null

Returns the header element associated with the specified panel name, or null if not found.

  • panelName string - The name of the panel whose header to retrieve
getPanel(panelName): HTMLElement | null

Returns the panel element with the specified name, or null if not found.

  • panelName string - The name of the panel to retrieve
openPanel(panelName): void

Opens the panel with the specified name. Closes any currently open panel first. Dispatches an openpanel event.

  • panelName string - The name of the panel to open
closePanel(panelName): void

Closes the panel with the specified name. Dispatches a closepanel event.

  • panelName string - The name of the panel to close
togglePanel(panelName): void

Toggles the panel with the specified name (opens if closed, closes if open). Dispatches a togglepanel event.

  • panelName string - The name of the panel to toggle

Events

openpanel

Fired when a panel is opened. The event detail contains { panelName }.

closepanel

Fired when a panel is closed. The event detail contains { panelName }.

togglepanel

Fired when a panel is toggled. The event detail contains { panelName }.
