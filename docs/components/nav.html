Slots

A semantic navigation bar component. When fixed is set, it automatically positions itself at the top of the viewport and applies elevation level 5 (z-index: 50), keeping it above push-mode drawers and below overlay-mode drawers — no manual z-index needed.

Content is placed via a default slot. Apply background and other visual styles with kempo-css utility classes directly on the element.

Fixed Navbar

Add the fixed attribute to pin the nav to the top of the viewport. Add a spacer element after it so page content is not hidden beneath it.

My App Account 
<k-nav fixed class="bg-primary">
  <button no-collapse>Menu</button>
  <a href="/" no-collapse>My App</a>
  <a href="/account" slot="right">Account</a>
</k-nav>

Inline Navbar

Without fixed, the nav sits in normal document flow.

My App Account 
<k-nav class="bg-primary">
  <button no-collapse>Menu</button>
  <a href="/" no-collapse>My App</a>
  <a href="/account" slot="right">Account</a>
</k-nav>

Collapsing

A nav never wraps. When its links and buttons no longer fit they move, one at a time, into a vertical-ellipsis “more” menu, and move back as the nav grows. It is a <k-control-bar>, so the same attributes work on its children: no-collapse keeps a link or button in the bar, priority moves it later, soft-min-width keeps a control from being squeezed, and slot="center" or slot="right" place it. The default slot is the left side and right is pinned to the right, so no spacer element is needed (an old <div class="flex"> spacer still works). Every child can move (links, buttons, a search box, a theme switcher) except spacers (.flex), menus, dropdowns and anything with no-collapse.

<kc-nav-link> is a link control for icon-only links. Put the icon in the default slot; its label is the menu-text slot (or the title when there is none), and it only shows while the link is in the menu. Drag the right edge of the example to see it.

My App Products Pricing Docs View on npm 
<k-nav class="bg-primary">
  <a href="#" class="d-if ph" no-collapse>My App</a>
  <a href="#">Products</a>
  <a href="#">Pricing</a>
  <a href="#">Docs</a>
  <kc-nav-link slot="right" href="https://github.com/dustinpoissant/kempo-ui" target="_blank" title="GitHub">
    <k-icon name="github-mark"></k-icon>
  </kc-nav-link>
  <kc-nav-link slot="right" href="https://www.npmjs.com/package/kempo-ui" target="_blank" title="npm">
    <k-icon name="npm"></k-icon>
    <span slot="menu-text">View on npm</span>
  </kc-nav-link>
</k-nav>

Attributes & Properties

Attribute / Property Type Default Description
fixed Boolean false Pins the nav to the top of the viewport (position: fixed) and applies elevation level 5 (z-index: 50).
collapse-order String "right center left" Which slot is emptied into the “more” menu first, always starting with its last item (left is the default slot).

Slots

Slot Description
default All nav content — buttons, links, dropdowns, etc. This is the left side.
center Links and buttons centered between the left and right sides.
right Links and buttons on the right side. These move into the menu first.
