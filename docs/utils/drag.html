Description

The drag utility function enables drag interactions on DOM elements. It handles both mouse and touch events, providing callbacks for drag start, move, and end events.

Basic Usage

Import and use the drag function to make elements draggable:

import drag from './utils/drag.js';

const element = document.querySelector('.draggable');
drag({
  element,
  callback: (diff) => {
    console.log('Dragged:', diff.x, diff.y);
  }
});

Options

element: HTMLElement

The DOM element to make draggable.

preventScroll: boolean (optional)

Whether to prevent scroll behavior during drag. Defaults to false.

Callbacks

callback: Function (optional)

Called on every drag move. Receives a diff object with x, y coordinates and original options.

startCallback: Function (optional)

Called when drag starts. Receives the starting event.

moveCallback: Function (optional)

Called on every drag move (in addition to callback). Receives a diff object.

endCallback: Function (optional)

Called when drag ends. Receives the ending event.

Examples

Draggable Element

const box = document.querySelector('.box');
let position = { x: 0, y: 0 };

drag({
  element: box,
  callback: (diff) => {
    position.x += diff.x;
    position.y += diff.y;
    box.style.transform = `translate(${position.x}px, ${position.y}px)`;
  }
});

Resize Handle

const resizeHandle = document.querySelector('.resize-handle');
const panel = document.querySelector('.panel');

drag({
  element: resizeHandle,
  preventScroll: true,
  callback: (diff) => {
    const newWidth = panel.offsetWidth + diff.x;
    panel.style.width = Math.max(100, newWidth) + 'px';
  },
  startCallback: () => {
    panel.classList.add('resizing');
  },
  endCallback: () => {
    panel.classList.remove('resizing');
  }
});
