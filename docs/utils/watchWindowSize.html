Description

The watchWindowSize utility provides a debounced way to monitor window resize events. It manages multiple handlers efficiently and automatically debounces resize events to improve performance.

Basic Usage

Import and use the window size watching functions:

import { watchWindowSize, unwatchWindowSize } from './utils/watchWindowSize.js';

const handler = (width) => {
  console.log('Window width:', width);
};

// Start watching
const currentWidth = watchWindowSize(handler);

// Stop watching when done
unwatchWindowSize(handler);

Functions

watchWindowSize(handler)

Registers a handler function to be called when the window is resized.

  • handler: Function that receives the new window width
  • Returns: Current window width
unwatchWindowSize(handler)

Unregisters a previously registered handler function.

  • handler: The same function reference that was registered

Examples

Responsive Component

import { watchWindowSize, unwatchWindowSize } from './utils/watchWindowSize.js';

class ResponsiveComponent extends LitElement {
  constructor() {
    super();
    this.isMobile = false;
    this.resizeHandler = this.handleResize.bind(this);
  }

  connectedCallback() {
    super.connectedCallback();
    const currentWidth = watchWindowSize(this.resizeHandler);
    this.handleResize(currentWidth);
  }

  disconnectedCallback() {
    super.disconnectedCallback();
    unwatchWindowSize(this.resizeHandler);
  }

  handleResize(width) {
    this.isMobile = width < 768;
    this.requestUpdate();
  }

  render() {
    return html`
      <div class="${this.isMobile ? 'mobile' : 'desktop'}">
        Content adapts to screen size
      </div>
    `;
  }
}

Multiple Handlers

// Handler for navigation
const navHandler = (width) => {
  const nav = document.querySelector('.navigation');
  nav.classList.toggle('mobile', width < 1024);
};

// Handler for sidebar
const sidebarHandler = (width) => {
  const sidebar = document.querySelector('.sidebar');
  sidebar.style.display = width < 768 ? 'none' : 'block';
};

// Both handlers will be called on resize
watchWindowSize(navHandler);
watchWindowSize(sidebarHandler);

// Clean up when needed
unwatchWindowSize(navHandler);
unwatchWindowSize(sidebarHandler);

Breakpoint Detection

const breakpoints = {
  mobile: 768,
  tablet: 1024,
  desktop: 1200
};

const breakpointHandler = (width) => {
  let currentBreakpoint = 'mobile';
  
  if (width >= breakpoints.desktop) {
    currentBreakpoint = 'desktop';
  } else if (width >= breakpoints.tablet) {
    currentBreakpoint = 'tablet';
  }
  
  document.body.setAttribute('data-breakpoint', currentBreakpoint);
  
  // Dispatch custom event
  window.dispatchEvent(new CustomEvent('breakpointchange', {
    detail: { width, breakpoint: currentBreakpoint }
  }));
};

watchWindowSize(breakpointHandler);

Performance Benefits

The utility automatically debounces resize events, so you don't need to worry about performance:

// This handler will only be called after resize events stop
const expensiveHandler = (width) => {
  // Expensive DOM calculations or API calls
  recalculateLayout();
  updateCharts();
  reflow();
};

watchWindowSize(expensiveHandler); // Automatically debounced
